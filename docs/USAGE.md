# OhGithubLost 使用说明

> **文档级别**：操作指南（Task-oriented Guide）
> **适用读者**：OGL 的终端使用者
> **约定**：每节均按「前置条件 → 步骤 → 预期结果」组织；故障排查统一收录于文末「故障排除」。

## 关于本应用

OhGithubLost（OGL）是一款 GitHub 仓库管理客户端，支持 Android、Windows、Linux 与 Web。读者可借助 OGL 浏览与编辑仓库、处理 Issues 与 Pull Requests、查看 Releases 与 Actions、管理 Gist，而无需打开浏览器。

## 适用平台

| 平台 | 状态 | 说明 |
| --- | --- | --- |
| Android | 支持 | 当前主要目标；4 架构 APK + AAB |
| Windows | 支持 | x64 / arm64；长路径建议开启 |
| Linux | 支持 | x64 / arm64；deb / rpm / AppImage；glibc ≥ 2.35（Ubuntu 22.04 一代及以上） |
| Web | 支持 | 在线访问 <https://oghapp.344977.xyz/>，无需安装 |
| macOS / iOS | 已弃用 | 最后支持版本 v5.3.0 |

macOS 与 iOS 的构建产物为未签名包，设备上不能直接安装使用。

## 登录 GitHub 账号

### 前置条件

- 已准备好 GitHub 个人访问令牌（Personal Access Token）。创建时按需勾选作用域，建议勾选 `repo`（可操作私有仓库、Issues 等）。
- 若不打算登录，也可继续以「游客身份」浏览公开内容。

### 步骤

1. 启动 OGL，进入登录页。
2. 在令牌向导中粘贴令牌，进入验证步骤。
3. 验证通过后保存令牌；向导将自动回读自检，每一步的进展与失败原因会逐项显示。
4. 登录成功。

> 令牌仅保存在本机系统密钥库；界面与日志中显示为脱敏形式；退出登录会移除本机令牌，远端数据不受影响。

### 预期结果

登录成功后，「我的」页显示当前账号头像与登录名；首页可同步加载该账号的仓库列表。

## 完成首次权限引导

### 前置条件

- 已首次启动 OGL。

### 步骤

1. 在首次启动的引导页阅读每项权限说明及其用途。
2. 按系统弹窗授予所需权限。
3. 若系统拒绝了某项权限，OGL 会提示前往系统设置开启。

### 预期结果

权限授予成功后，后续访问对应能力（文件、通知、存储等）不再被拦截；权限缺失时，应用内对应操作会如实提示并提供跳转入口，而非虚报已授权。

引导页之后可经「设置 → 维护 → 权限与引导」随时重看。

## 浏览首页

### 前置条件

- 已登录 GitHub 账号（游客身份仅可浏览公开仓库）。

### 步骤

1. 打开底部 / 侧边的「首页」入口。
2. 在「我的仓库」与「星标仓库」之间切换。
3. 下拉刷新列表。
5. （可选）点击右上角新建仓库，填写名称、描述与是否私有后提交。

### 预期结果

首页列表展示当前账号可见的仓库；下拉刷新会重新拉取远端列表；新建仓库成功后跳转至该仓库页。

## 搜索仓库与代码

### 前置条件

- 无（搜索为公开能力）。

### 步骤

1. 打开「搜索」入口。
2. 在「仓库」与「代码」之间切换搜索范围。
3. 输入关键字，按回车执行。

### 预期结果

仓库结果进入对应仓库页；代码结果直达该仓库中的对应文件。

## 在仓库页内操作

### 前置条件

- 已打开目标仓库页。

### 步骤

1. 在顶部对仓库进行星标 / 取消星标或复刻。
2. 在以下八个标签中选择当前任务：

   | 标签 | 操作能力 |
   | --- | --- |
   | 代码 | 目录浏览（文件夹排在文件前），按类型显示图标；点文件查看内容；长按（手机）或右键（桌面）弹出下载、详情、删除菜单；进入编辑可修改并提交。 |
   | Issues | 列表与筛选；详情含正文与评论；可新建议题、发表评论、关闭或重开。 |
   | Pull Requests | 列表与详情；展示变更文件与增删行统计；有补丁时可展开查看。 |
   | Releases | 列表与详情；查看说明、下载附件；新建、编辑（标签 / 标题 / 说明 / 草稿 / 预发布）、删除。 |
   | 分支 | 列表；新建、重命名、删除。 |
   | 提交 | 历史列表；详情展示该次变更文件与分色补丁。 |
   | Actions | 运行列表；详情展示作业与步骤、状态与耗时；可重新运行、取消；可手动触发支持手动触发的工作流（选择工作流、填写分支与参数）。 |
   | 设置 | 编辑仓库名称与描述、配置自定义域名（CNAME）、启用 Pages、删除仓库（二次确认）。 |

### 预期结果

所选操作的远端结果应在 10–30 秒内反映到仓库页；危险操作（删除、强制覆盖）会触发二次确认。

## 使用代码编辑器

### 前置条件

- 已在仓库页进入目标文件的编辑模式。

### 步骤

1. 在编辑器中修改文件内容。
2. （可选）使用撤销 / 重做、查找与替换、切换自动换行与字号。
3. 保存。
4. 若弹出冲突提示，按提示选择取消或强制覆盖。

> 编辑器带基线校验：若远端已被他人更新，OGL 不会直接覆盖，而是弹出冲突提示（显示本地基线、远端最新与远端内容）。返回未保存文件时，应用会先弹出确认。

### 预期结果

保存成功后改动进入提交流程；冲突时 OGL 不会覆盖远端，必须由使用者显式选择取消或强制覆盖。

## 管理 Gist 片段

### 前置条件

- 已登录 GitHub 账号。

### 步骤

1. 在「我的」页进入 Gist 入口。
2. 选择「新建 / 编辑 / 删除」中的目标动作。

### 预期结果

对 Gist 的改动立即同步到 GitHub 远端；详情页展示最新内容。

## 使用下载管理

### 前置条件

- 已触发一次或多次下载任务（Release 附件、仓库文件、Gist 等）。

### 步骤

1. 在首页右上角点击下载图标进入下载管理。
2. 在任务列表中查看实时进度与速率。
3. 对单个任务执行暂停、继续、取消、重试或移除。

> OGL 内置多连接分片下载，支持断点续传；落盘位置为应用根目录 `ogl/download/<分类>/`（Release、仓库文件、Gist 分别归类）。Release 附件下载可经**用户自备的加速通道**；本应用不预置任何代理，不添加则直连。

### 预期结果

任务列表显示每个下载的进度、速率与最终状态；任务完成后落盘文件可在应用根目录 `ogl/download/<分类>/` 下找到。

## 使用草稿箱

### 前置条件

- 至少在编辑器中触发过未提交的改动。

### 步骤

1. 在「我的」页进入草稿箱。
2. 查看草稿列表，可复制或清理。
3. 再次进入同一文件时，OGL 会自动恢复草稿并提示。

> 编辑器自动把未提交的改动存为草稿；提交成功后草稿自动清除。

### 预期结果

未提交的改动在重启 / 切换文件后仍可恢复；草稿列表内容可复制用于反馈。

## 查看通知中心

### 前置条件

- 无（通知为本地运行事件汇总）。

### 步骤

1. 在首页右上角点击铃铛图标进入通知中心。
2. 按「全部 / 告警 / 错误」筛选。
3. 单条通知可复制用于反馈。

### 预期结果

通知中心汇总运行事件（成功、告警、错误）；筛选后仅显示符合条件的事件。

## 维护多账号

### 前置条件

- 至少已登录一个 GitHub 账号。

### 步骤

1. 在「我的」页切换当前账号。
2. 添加新账号：粘贴令牌、验证、保存。
3. （可选）移除账号或退出登录（删除本机令牌）。

### 预期结果

切换账号后，首页与权限范围立即反映新账号；移除 / 退出登录后本机令牌被删除，远端数据不受影响。

## 调整设置

### 前置条件

- 无。

### 步骤

1. 打开「设置」页（默认折叠，按需展开分组）。
2. 按需调整各分组项。

设置分组涵盖：

- **外观**：明暗模式、主题色、界面密度、文字缩放、动效档位（最小 / 当前 / 标准 / 增强）。
- **语言**：6 种界面语言（简体中文 / 繁體中文 / English / Deutsch / Français / Русский）。
- **代码与文件**：语法高亮开关、高亮主题（跟随主题 / 高对比 / 柔和 / 自定义逐项配色）、自动换行、代码字号、目录优先排序。
- **网络**：自定义 DNS 解析、DNS 服务器、DoH（加密解析）。
- **账户**：当前账号与退出。
- **维护**：权限与引导、重置设置。
- **关于**：独立页面，展示项目名称、主要开发者、版本、仓库地址、许可与启动诊断。
- **开源许可**：本项目许可与第三方依赖清单。
- **日志**：日志文件位置与复制入口。
- **捐赠一颗心**：二次确认后，用当前登录账号为本项目加星；已 star 时不会重复操作。

### 预期结果

每项设置调整后立即生效；动效档位与语言变更在下一次启动仍保留。

## 反馈问题

### 前置条件

- 已复现问题一次。

### 步骤

1. 复现问题。
2. 在「设置 → 日志」复制日志内容。
3. 在 [Issues](https://github.com/OGL-Teams/OhGithubLost/issues) 中提交 Issue，附日志与复现步骤。

### 预期结果

维护者收到带日志与复现步骤的 Issue 后可定位根因；提交后 Issue 页面将出现对应的反馈链接。

## 故障排除

| 症状 | 可能原因 | 对策 |
| --- | --- | --- |
| 安装新版提示「应用签名不一致」 | 早期版本的签名证书已更换 | 安装 v1.1.0 及之后版本前，先卸载旧版一次，之后即可正常覆盖升级 |
| 保存文件时弹出冲突 | 远端在你打开文件后有新提交 | 取消以保留远端，确认内容后再改；确认要放弃远端改动时选强制覆盖 |
| GitHub 令牌权限不足 | 令牌作用域未覆盖当前操作 | 到 GitHub 重新生成令牌，勾选所需作用域（如 `repo`），再在「我的」里添加账号 |
| Release 附件下载缓慢 | 默认直连，无加速通道 | 自备加速通道，在「设置 → 网络」或下载选项中按提示配置；本应用不预置任何代理 |
| 启动后进入「安全模式」 | 引导清单签名或模块完整性校验失败 | 查看「关于 → 启动诊断」获取详情；通常由应用安装包损坏引起，请重新下载并安装 |

## 数据可靠性与隐私

- **文件锁**：保存与删除均带基线校验；远端有他人改动时会被拦下并提示，而不是直接覆盖。
- **操作反馈**：加载中、无内容、出错、成功四类状态均会显示；危险操作会二次确认。
- **网络不稳**：请求会自动重试；连接失败时会把更底层的原因写进日志，便于定位。
- **网络受限**：可在设置中选择自定义 DNS 与 DoH。
- **令牌保管**：令牌只存本机密钥库，日志与报错中脱敏，退出登录即删除。
- **出错可见**：未捕获的错误会以弹窗或横幅提示；可随时在设置中复制日志用于反馈。
- **启动校验**：启动时校验内置引导清单的签名与模块完整性；异常时进入安全模式，并在关于页说明。
