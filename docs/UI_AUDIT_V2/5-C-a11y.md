## 二、回归（v15 大改有无新问题）

1. **48dp 覆盖核对**：rg 全量核对 IconButton（65）/InkWell/GestureDetector（75 处交互）——IconButton/各按钮走主题 minimumSize 真实生效；ListTile 行默认 ≥56dp；**未覆盖**：Chip 族（chipTheme padding vertical xxs=4，M3 默认高 32 + labelSmall → 实际高约 34-38dp <48，search_page 筛选胶囊行、设置页 chip）→ P1-1。
2. **对比度核对**：`tool/contrast_audit.py` 实跑 0 处问题；但该工具**只审暗色**（`_extract_colors(source, dark=True)`、containers 仅暗色 4 档），浅色全靠人工——工具覆盖缺口（P2-4）。手工算关键组合（MD3 tone 基线）：
   - onSurface 对 surface/各 container：14.35-16.23:1 ✅
   - onSurfaceVariant（次要文字）对各级容器：7.20-10.91:1 ✅（远超 4.5）
   - primary 对各级容器：4.97-10.91:1 ✅
   - **warning #B26A00 对浅色 surface 4.03:1 <4.5**（作正文级文字不足，作大字/图标 ≥3 达标）→ P2-3
   - success 对暗 surface 3.63:1：仅图标级达标，若作暗色正文不足 → P2-3
3. **导航轨主题**：navigationRailTheme 与 navigationBarTheme 同语言（surfaceContainerLow/primaryContainer 药丸，theme.dart:364-380）✅ 一致性无回归。
4. **200% 缩放风险**：code_editor_toolbar.dart:117-172 一行 7 个 IconButton（各 48dp min）+ 搜索框，窄窗/横竖屏切换时 Row 无滚动包裹，有溢出风险（静态推断，未实机）→ P2-5。

（两处均在 ListTile 内，读屏可落在行节点，但作为独立焦点时无名）

### ③ 可点击但无 Semantics 声明的自定义元素
- discover_rows.dart OgLFeedRow：有 button+label，但 **excludeSemantics 丢了 unread 状态**——读屏用户听不出未读/已读（视觉仅靠 4px 竖条）→ P1-3
- scroll_aware_action.dart:368 GestureDetector：有 hint 无 role/button 声明，且不可键盘聚焦 → P1-2
- desktop_window.dart:145 标题栏拖拽区：双击最大化无语义（桌面辅助技术无法触达窗口控制）→ P2

### ④ 正文/次要文字对比不足组合
- warning 色作浅色正文（4.03:1）——见回归 2
- disabled 前景 onSurface@60% alpha（theme.dart:469/477/490/499）：约 5-6:1，勉强达标但接近边界，建议调 0.52→留 0.60 不动亦可，列为观察项

### ⑤ 同类页面模式差异
- AppBar 两套：15 页 OgLAppBar（滚动渐变）vs 15 页裸 AppBar（仅 scrolledUnderElevation）→ **P1-4**
- 分页：perPage 10/20/30 三种、自动/手动加载混用 → P1-5
- 空态写法：gists/drafts/settings 各自内联空态文案，无统一空态组件（无 CTA 的一致性问题归 3-B，本席只记模式差异）

### ⑥ 键盘可达性
- shortcuts.dart 提供全局快捷键层 ✅
- ListTile/InkWell 行 Flutter 默认可 Tab 聚焦 + Enter 激活 ✅
- 不可聚焦：scroll_aware 收边 tapLayer（GestureDetector 无 focus 支持）、桌面标题栏拖拽区、横向 SingleChildScrollView 的筛选胶囊行（Tab 可进 chip 本身，但无法键盘横滚）→ P2

## 四、分级汇总

**P0**：无。

**P1**
1. **Chip 命中区 <48dp**：chipTheme 实际高约 34-38dp。修复指令：theme.dart chipTheme `padding` vertical 改 `OgLSpace.xs`(8) 并加 `labelPadding`，或设 `visualDensity` 抵消；确保 FilterChip 总高 ≥48。
2. **scroll_aware 收边元素不可键盘/读屏激活**：scroll_aware_action.dart:368 的 tapLayer 外包 `Focus(...)+Shortcuts(Enter/Space→onTap)` 并在 Semantics 加 `button:true`。
3. **OgLFeedRow 未读状态无语义**：discover_rows.dart:69-73 改为 `Semantics(button:true, label:'$title，$meta', flag: unread? ... )`——用 `Semantics(checked:)` 或在 label 前拼「未读，」前缀，移除 excludeSemantics 对 unread 的丢失。
4. **两套 AppBar**：issue_page:763、notifications_page:159、commit_page:93、gist_detail_page:340、release_detail_page:458、file_preview_page:206、code_editor_page:579、action_run_page:526、action_log_page:290、pull_page:109、download_manager_page:191、workflow_dispatch_page:413、new_gist_page:144、legal_text_page:100、login_page:326 全部改 `OgLAppBar`（OgLAppBar 已实现 actions/bottom 参数，迁移无阻塞）。
5. **分页模式统一**：新增统一分页常量（建议 perPage=30）与统一 load-more 触发（滚动到底 + 底部手动按钮兜底二选一），search_page:483/589/1258、notifications_page:434 对齐。

**P2**
1. settings_page:1613、gists_page:180 两处 IconButton 补 tooltip（复用行文案作 tooltip 即可）。
2. desktop_window 标题栏：给窗口控制钮加 Semantics（最小化/最大化/关闭已有按钮则核对 label），拖拽区声明 `Semantics(label:'标题栏')`。
3. warning 色浅色正文对比 4.03:1：theme.dart:305 warning 调深至约 #8F5300（对 #FEF7FF ≥4.5）或约束 warning 仅作图标/徽标级使用并在注释写明。
4. tool/contrast_audit.py 补浅色容器档（surface 4 档 × 明色）对称断言，防浅色回归（当前 dark=True 硬编码）。
5. code_editor_toolbar 7+ 控件单行 Row：外包横向 SingleChildScrollView 或按窗口宽断行，防窄窗/200% 字号溢出。
6. 筛选胶囊横向滚动区补键盘滚动手势（Focus + 左右键）。

## 五、用户满意度（三问之外的直答）

- **戴眼镜/低视力**：正文 16.2:1、次要文字 7.2:1+，远超 AA；主要短板是 Chip 命中区小、warning 色浅色正文偏淡——修 P1-1/P2-3 后达标。
- **读屏用户**：行级语义（ListTile/OgLFeedRow/scroll_aware）基本可用，但状态信息（未读、加载中、禁用原因）多以纯视觉表达；P1-2/P1-3 修复后旅程完整。
- **不同屏幕尺寸**：窄屏主要风险是 toolbar 溢出（P2-5）与 chip 行横向滚动可达性；宽屏 rail 与 navbar 已统一，信息不丢。

## 本席对三问的回答

1. **闭环**：9 条核对——B-05/G-05/A-M1/A-M2/C-S2 已修；A-M3 修法有问题（语义覆盖不全、状态语义缺失）；C-S1（两套 AppBar 15/15）、C-S6（分页混乱）未修；G-11 部分已修。
2. **回归**：48dp 主题层真实生效但有 Chip 族漏洞；对比度整体达标（onSurfaceVariant ≥7:1），工具只审暗色是门禁缺口；rail/navbar 主题一致无回归；200% 缩放下 toolbar 有溢出风险。
3. **新发现**：P1×5（chip 命中区、scroll_aware 键盘/语义、未读状态语义、AppBar 二分、分页模式）、P2×6（2 处无名图标钮、warning 4.03:1、对比工具浅色缺口等）。
