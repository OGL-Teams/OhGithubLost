# 多语言（i18n）维护手册

> 目标：**界面文案一律不得硬编码中文**；新增页面 / 文案须遵循固定流程，遗漏翻译与
> 结构回退由 CI 门禁拦截。

## 1. 结构

```
assets/i18n/<locale>/<page>.json     # 一种语言一个目录，一个页面一个分片
lib/surface/i18n/og_l_i18n.dart      # 内核：t(page, key, {args}) + locales/pages 清单
lib/surface/pages/<x>_page.dart      # 页面代码：只出现 t('x_page', 'key')
tool/i18n_scan.py                    # 抽取 + 校验（CI 门禁）
tool/i18n_wire.py                    # 批量接线（把中文字面量换成 t()）
tool/sort_imports.py                 # import 分组排序（directives_ordering）
```

- **6 种语言**（v6.4.0 起；此前为 15 种）：`zh`（源）/ `zh_TW` / `en` / `de` /
  `fr` / `ru`。
- **收敛原因**：原 15 种语言中有 12 种的法律类正文实为英文占位 —— 用户看到的
  是自己无法阅读的法律文本。相较让 9 种语言仅存名义，本版本将保留的每一种都做到
  可读。恢复某个语种的前提是**全部键均为真实译文**，而非复用英文。
- 键名小驼峰、语义化（`commentPosted` 而非 `text1`）；一个键只放一条文案。
- 分片格式固定：**2 空格缩进 + 键排序 + 末尾换行**（写入须统一经脚本，不得手工修改格式）。

## 2. 取文案

> **首次启动**跟随系统语言（`zh` 会按区域细分：繁体系统 → `zh_TW`），
> 之后一律以用户在设置页选择的语言为准（落盘、重启保留）。

```dart
/// 页面顶部（或工具文件）放一个 `_t` 助手：
String _t(String key, [Map<String, Object?>? args]) =>
    OgLI18n.instance.t('my_page', key,
        args: args?.map((String k, Object? v) => MapEntry<String, String>(k, '$v')));

Text(_t('title'))                       // 静态文案
Text(_t('deleted', {'path': path}))     // 文案里写 `{path}`
```

兜底顺序为：**当前语言 → 英文基线 → 键名**，绝不返回空串；参数缺失时保留 `{name}` 原文
而不抛出异常。

## 3. 新增一条文案（标准流程）

1. 在 `assets/i18n/zh/<page>.json` 加键（值写中文，术语 GitHub / Release /
   Actions / PR / Token / Pages / Commit / OhGithubLost **不译**）。
2. 代码里改用 `_t('键')`；若该行原本在 `const` 里，去掉 `const`。
3. 跑 `python3 tool/sort_imports.py`。
4. 翻译其余 14 种语言（增量模式，只翻新键、合并进现有分片）：

   ```bash
   cd _setup
   python3 ogl_i18n_translate.py --page <page> --keys 键1,键2 --locales all --rpm 8 --concurrency 3
   ```

5. 本地自检：`python3 tool/i18n_scan.py --check`（必须 0 失败）。

## 4. 新增一个页面

1. 完成页面代码，界面文案**全部**经 `_t` 取值。
2. `lib/surface/i18n/og_l_i18n.dart` 的 `pages` 列表加页面名（不加则分片不会被加载）。
3. 新建 `assets/i18n/zh/<page>.json`；若目录是新的，`pubspec.yaml` 的 `assets:` 也要加。
4. 译 14 种语言：`python3 ogl_i18n_translate.py --page <page> --locales all`
   （合并模式：一个语种一次请求，整页一起给模型）。
5. `tool/i18n_scan.py --check` + `flutter test test/surface/i18n_test.dart`。

## 5. 门禁（CI 执行，违反即判定失败）

| 命令 | 检查什么 |
|---|---|
| `python3 tool/layer_audit.py --fatal` | 依赖只能 `surface → domain → base → kernel` |
| `python3 tool/i18n_scan.py --check` | ① 界面文案 0 处未本地化 ② 6 语言分片键集合与 zh 完全一致 |
| `flutter analyze --fatal-infos` | 含 `directives_ordering`（用 `tool/sort_imports.py` 修） |
| `flutter test` | 含 `test/surface/i18n_test.dart`（分片存在性 / 键集合 / 术语保留） |

### 「界面文案」的判定范围

- **属于界面文案**：出现在 `Text` / 按钮 / 提示 / 校验错误 / 对话框 / 通知中的字符串。
- **不属于界面文案（按设计保留中文）**：`OgLAppLog` / `OgLLogFile` / `debugPrint` /
  `throw` / `assert` 中的**开发者日志与诊断**；非交互层（`kernel` / `base` /
  `domain`）的全部字符串；`og_l_i18n.dart` 中的语言自称（「简体中文」在任何
  语言下均显示原文）。
- 少数「先拼接字符串、稍后才落盘」的日志载荷无法被扫描器识别，须在字符串上方加一行
  `// i18n-allow: 说明` 显式豁免（**仅在确非界面文案时使用**）。

## 6. 翻译工具速查（`_setup/`，本机脚本，不纳入仓库）

```bash
python3 ogl_i18n_translate.py --all --locales all --rpm 9 --concurrency 3   # 全量
python3 ogl_i18n_translate.py --page repo --locales ja,ko                    # 单页多语
python3 ogl_i18n_translate.py --page common --keys a,b --locales all         # 增量补键
python3 ogl_i18n_translate.py --all --locales all --dry-run                  # 只估 Prompt 体积
```

- 默认**合并模式**：一个语种对应一次 API 调用（27 页一并处理），失败自动回退重翻。
- 校验项：JSON 可解析 / 键集合一致 / 占位符完整 / 值非空 / 非 CJK 目标语言不得残留中文。
- 实时多行进度面板（ANSI 原地刷新 + 转圈动画 + 每语种耗时 / 尝试次数 / ETA）。
