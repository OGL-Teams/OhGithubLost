## 四、两批交叉的元结论

- **批 1（网络）+ 批 2（磁盘）共抓出 5 个真实 P0**：
  1. 守卫首跳丢 body（批1 A-01）
  2. 302/303 错降级 GET（批1 A-04）
  3. `CacheRemote.write` 自锁死锁（批2 A-01）
  4. D1 误判「远端不存在」致静默覆盖（批2 A-05）
  5. （已降级）C-06「防线有开关」经复读为合法例外
- 前 4 个**全部指向同一个用户症状「提交不可用 / 提交报 206」**——说明多视角交叉 + 主会话亲自复读 P0 能有效剥开层层叠加的根因。
- C 视角两批都点名**同一个结构性问题**：`layer_audit.py` 不解析 `export`、`motion/perf_audit.py` 只扫 `lib/surface/`，`lib/base/` 与 `lib/domain/` 的语义缺陷在 CI 全绿下共存。这是 8 批计划里最该补的一支门禁。
