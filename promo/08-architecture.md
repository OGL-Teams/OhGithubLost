## 5. 动效规则

- 禁止全片统一横滑。**每个场景进入用不同类型**（见上表），相邻不得重复。
- 位移基准：内容 24/32/48px；转场 80/120px；时长 180/240/300/420ms；缓动 `power2/3/4.out`，退出 `power3.in`。
- 每屏至少 3 倍速差：铺垫 600ms / 触发 80ms / 收束 240ms。
- 光标是节拍器：慢巡航 600ms → 急停 80ms → UI 响应 240ms。
- 物理感（无弹簧库）：位移拆两段，0→106%（140ms power3.out）+ 106%→100%（220ms power2.inOut）。
- 代码行永不弹性：clip-path 逐行揭示，线性 70ms/行。

- 片头第 0 帧：2px 主色线已存在（不是黑屏）。
