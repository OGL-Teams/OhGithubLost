## 核心原则（本轮重写原因）

上一版被否：空泛无力、没有功能、切换死板、动画无力、片头黑屏。
本版规则：

1. 每屏必须有一个**真实界面动作**（点击 → 状态变化 → 结果），文案只是注脚。
2. 相邻转场类型不重复：纵向展开 / 向下揭示 / 容器变换 / 从下升起 / 横向揭示 / 从右滑入 / 圆形展开 / 错峰升起 / 表格落下。
3. 第 0 帧已有 2px 主色线，不存在黑场。
4. 音乐前 40s 静默，只在动作密度上升时进入。
