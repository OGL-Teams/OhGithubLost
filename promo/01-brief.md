## 2. 产品定位

OhGithubLost（OGL）：把 GitHub 的仓库、议题、PR、发布、Actions、Gist 搬进本地窗口的 Flutter 客户端。Android / Windows / Linux / Web 四平台，6 语言，Apache-2.0。

**一句话（新手向）**：第一次用 GitHub，也能直接上手。
**一句话（极客向）**：失败如实可见，四层依赖零越级。

## 5. 音乐与卡点（本轮替换）

**HOYO-MiX《子不语 Wordless》**，挂载目录 `/var/minis/mounts/Tiernan_Music`；取原曲 28–84s 共 56s 裁段，转 44.1kHz 立体声 MP3（`assets/audio/wordless-56s.mp3`）供浏览器稳定解码。

- 8k 单声道频谱通量分析得到 106 个强 onset，主副歌能量峰在 14–22s 与 38–52s。
- 场景切点按真实 onset 重定时：`0 / 6.8 / 14.1 / 23.0 / 32.2 / 40.2 / 46.2 / 52.3 / 56`。
- 根 composition 在 7 个切点做 0.07s 闪入 + 0.24s 淡出的 `#beat-flash`（品牌蓝径向光），仅作节奏提示，不抢画面。
- 原 96 BPM 代码合成 BGM 保留为 `bgm.wav` 备用轨（`data-volume=0`），CI 仍逐字节复现校验。
- **版权提示**：歌曲版权归原作者所有，`wordless-56s.mp3` 仅随 `video` 分支用于本次样片；正式对外投放前须确认授权或换回合成 BGM。
