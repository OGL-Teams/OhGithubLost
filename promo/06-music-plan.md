# OGL 宣传片 · 配乐（06-music-plan）· 180s

## 编排

| 项 | 值 |
|---|---|
| 源曲 | HOYO-MiX《子不语 Wordless》全曲 132.19s（挂载目录） |
| 工程文件 | `assets/audio/score-180s.mp3`，180.04s，4.12 MB，192 kbps |
| 生成 | `python3 promo/scripts/make_score.py`（40s 静默 + 132s 原曲 + 8s 尾收，再施加分段音量包络） |
| 版权 | 归原权利人；仅随 `video` 分支用于内部样片，正式投放前须授权或换曲 |

## 分段音量（对画面）

| 时间 | 音量 | 理由 |
|---|---|---|
| 0–40s | 0 | 片头与仓库目录：观众要先看懂"点了什么"，音乐会让节奏变成 MV |
| 40–52s | 0 → 0.5 | 进入长文件阅读，需要一层托底 |
| 52–100s | 0.5 | 编辑 / Issue / 日志：铺底，不抢文字 |
| 100–120s | 0.5 → 1.0 | 下载与 DNS：全片动作密度最高，音乐推到满 |
| 120–172s | 1.0 | 法律 / 多账号 / 产物：满档 |
| 172–180s | 1.0 → 0 | 片尾 CTA 收净 |

## 与旧版（56s Wordless 裁段）的区别

- 旧版：全片 56s 只有音乐，靠"卡点"制造节奏，结果画面被音乐拖着走。
- 新版：**音乐是配角**，前 40s 完全静默，靠界面动作与文案推进；音乐只在动作密度上升时出现，最后 8s 收干净。

## 若需换曲

1. 把新曲放到挂载目录，改 `scripts/make_score.py` 的 `SRC` 与 `MUSIC_LEN`；
2. 重跑脚本，校验时长 180s ±1s；
3. CI 只校验时长与可解码性（源曲不入库），不会因换曲失败。

## 备选：代码合成轨

`assets/audio/bgm.wav`（96 BPM，`scripts/make_bgm.py`）仍在仓库里，作为无版权方案；若要整片替换，把 `index.html` 的 `#bgm src` 指向它，并按需补一条 180s 的裁切/循环脚本。
