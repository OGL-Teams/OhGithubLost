## 与门禁的关系

- `flutter test` 是 CI 质量门之一（`.github/workflows/ci.yml` 严格模式：
  每步失败只记录，终审统一 fail）。
- 纯 Dart/Python 层的结构契约由 `tool/gate_of_gates.py` 统一自检：
  7 支门禁在临时 CWD 下仍须有能力，且能拦下人为注入的缺陷。
- 新增测试后请同步本表；覆盖表过期本身就是批 9 交叉审查点名的
  「文档数字静默腐烂」（C-18）之一。

运行：`flutter test`。
