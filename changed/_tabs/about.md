## 关于本页

本页为 OhGithubLost 的版本更新日志。每篇记录对应一个已对外发布的版本，按发布时间倒序排列。

## 支持的平台

| 平台 | 说明 |
| --- | --- |
| Android | 手机与平板，提供四种 CPU 架构的安装包 |
| Windows | 电脑，x64 与 ARM64 两种 |
| Linux | 电脑，x64 与 ARM64 两种 |

macOS 与 iOS 已停止维护，最后支持版本为 5.3.0。

## 如何选择安装包

- Android：不确定设备架构时，下载 universal 通用包即可覆盖绝大多数设备。
- Windows 与 Linux：多数电脑选择 x64；ARM 架构设备（如部分骁龙平台笔记本）选择 ARM64。
- 每个安装包同时提供 zip 与 7z 两种压缩格式，任选其一解压即可。

## 版本号说明

形如 9.5.0 的版本号为正式版，可放心使用；带 beta 或 alpha 后缀的为测试版，功能可能尚不完整。
