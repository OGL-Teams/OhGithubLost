**主题 · Theme** — **存储三档**（公共目录 → SAF → 应用内部）、网络设置独立成页、引导页重做（语言 / 外观前置），以及加速通道的内置优先链。
*Three-tier storage (public dir → SAF → internal), network settings as its own page, a reworked onboarding (language & appearance first), and a built-in acceleration priority chain.*

### 新增 · Added（存储 · Storage）

- **三档落盘 · Three storage tiers**

  | 档 | 条件 | 落点 | 用户可见 | 自检 |
  |---|---|---|---|---|
  | ① 公共目录 | 有「所有文件访问」 | `/storage/emulated/0/ogl` | ✅ | **过** |
  | ② SAF 文件夹 | 用户授权了文件夹 | 私有目录 → **导出粘贴**到该文件夹 | ✅ | **过** |
  | ③ 应用内部 | 两者都没有 | 应用私有目录 | ❌ | **不过**（不阻断） |

- **SAF 的落地方式**：下载**照旧**写应用私有目录（分片 / 断点续传 / 后台通知全部零改动），完成之后用 `SafStream.pasteLocalFile` 把成品**粘贴**进你自己选的文件夹。这样"用户看得见"与下载实现**解耦**，不需要重写下载引擎。
  *Downloads keep writing to the app-private directory (sharding / resume / background notifications untouched); the finished file is then pasted into the folder you picked.*

- **设置 → 存储位置**：如实显示**当前档位与实际路径**，并提供「选择文件夹（SAF）」「取消文件夹授权」「打开『所有文件访问』设置」。
- 新增事件码 `OGL-DL-301`（已导出到所选文件夹）。

### 变更 · Changed（引导 / 设置 · Onboarding & settings）

- **引导页新增第 1 步「语言与外观」**：语言与明暗模式**在引导里首次设定**、改完即时生效；引导**不含登录**——按商业规范，登录不属于引导流程。
- **登录页左上角**新增入口，可随时**重新触发引导**（回顾模式：不改动"已引导"标志，也不影响登录状态）。
- **网络设置独立成页**（DNS / 下载并发 / 加速通道），不再是一个可折叠分组。
- **开源许可合并为一条**，打开时弹窗（本项目 + 第三方依赖）。
- **加速通道内置优先链**：内置通道 = `gh.344977.xyz`（优先）+ `gh.felicity.ac.cn`（降级），用户**不可调整**；下载时逐个探测、**静默降级**，最后永远保留**直连**兜底。

### 变更 · Changed（图标 / 命名 / 平台 / 产物）

- **应用图标改为矢量、背景透明**：几何形状的唯一事实来源是 `assets/icon/ogl_icon.svg`；
  **Android 用矢量 XML**（`VectorDrawable` 前景 + 自适应图标，背景
  `@android:color/transparent`），不再依赖多倍率 PNG。
- **应用名**：**Android = OGL**；其余平台 = OhGithubLost。
- **平台调整**：**自 5.6.0 起弃用 macOS 与 iOS**（不再构建、不再发布）；
  **最后支持版本 = v5.3.0**。
  其余平台补齐 **ARM**：Windows（x64 / **arm64**）、Linux（x64 / **arm64**），
  且 arm64 由非阻塞改为**正式腿**（失败即阻塞发布）。
  > 桌面端**没有 32 位**目标（上游 Flutter 只提供 x64 / arm64），
  > 32 位产物仅 Android 有（`armeabi-v7a`）。
- **Release 只提供压缩包**：每个平台产物同时给出 **`.zip` 与 `.7z`**，
  且都用**极限压缩**（`zip -9` / `7z -mx=9`）；不再直传裸 APK / AAB / 平台目录。

### 修复 · Fixed

- **存储权限被误判为已授权**：探针以前探的是**回退之后的目录**，退回应用私有目录也会被判成"已取得权限"。现在改为探测**用户可见性**（`Android/data` 与内部存储一律**不算可见**）。
- **"给了所有文件权限仍用内部存储"**：根目录结果被**进程级缓存**，授权后不会重新解析；现在探针前会 `invalidate()` 并**重新解析**。
- **按 Android 版本如实说明**：未就绪时说明会追加"为什么"（Android 11+ 需要「所有文件访问」；部分 ROM 只支持逐个授权文件夹）与"现在落在哪"（实际路径）。
- 修正内置通道名称的文案分片（应取 `common` 分片），此前可能显示成键名。

### 已知限制 · Known limitations

- SAF **只作用于下载成品**（导出到所选文件夹）；日志与缓存仍在应用私有目录。
- ② 档下导出是**下载完成后**的一次性复制，大文件会多占用一份临时空间。
- 「所有文件访问」开关由系统 / ROM 决定，部分设备确实**不提供**——此时请用 SAF 文件夹。
- 数量有界的列表刻意保持急加载；分片下载的暂停 = 重新开始。
- 翻译由 AI 产出并通过格式 / 占位符校验，未逐条人工校对。

### 产物 · Artifacts

Android（`arm64-v8a` / `armeabi-v7a` / `x86_64` / `universal` APK / AAB）、Windows、Linux、macOS、iOS，以及引导清单 `boot-manifest.zip` —— 共 **19** 个文件。
Android (arm64-v8a / armeabi-v7a / x86_64 / universal APK / AAB), Windows, Linux, macOS, iOS plus the signed boot manifest — 19 files in total.
