**主题 · Theme** — 动效与设置里的「动效档位」联动，并补齐入场 / 三态过渡。
*Motion wired to the in-app motion level, with entrance and state transitions added.*

### 新增 · Added

- **动效档位体系 · Motion-level system**
  新增档位作用域与动效工具箱：动画时长与叠加效果按档位 0–3 联动——**0 关闭全部动画 / 1 仅淡入 / 2 淡入 + 位移 / 3 再叠缩放**（开销随档位递增）。  
  Added a scoped motion toolbox where duration and effects follow levels 0–3: off, fade only, fade + offset, and fade + offset + scale (cost grows with the level).
- **入场动画覆盖 · Entrance animation coverage**
  首页仓库、下载管理、通知中心、草稿箱，以及仓库页的 Issues / Pull Requests / Releases / 分支 / 提交 / Actions 列表统一入场。  
  Entrance animations now cover the home repository list, download manager, notification centre, drafts box and the repository page’s issues, PRs, releases, branches, commits and Actions lists.
- **加载 / 空 / 错误三态之间加入淡入淡出**，取代此前的瞬时切换。  
  Loading, empty and error states cross-fade instead of switching instantly.

### 变更 · Changed

- 新增 `docs/ANIMATION_PLAN.md`：把 3.2 的动效任务与性能代价对应起来。  
  Added `docs/ANIMATION_PLAN.md`, mapping the motion work to its performance cost.
- 分段选择位移、对话框曲线、共享元素等交互细项**移交 3.3**，本版不实现。  
  Segmented-control sliding, dialog curves and shared elements were deferred to 3.3.

### 测试 · Tests

- 新增分档与回退测试：时长随档位递增、降到 0 回退为零、叠加效果按档位生效。  
  Added tests asserting duration grows with the level, drops to zero at level 0, and that stacked effects apply per level.

Android（`arm64-v8a` / `armeabi-v7a` / `x86_64` / `universal` APK / AAB）、Windows、Linux、macOS、iOS —— 共 **19** 个文件。
