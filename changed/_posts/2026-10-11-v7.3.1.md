UI-detail fix batch: sheet close animation, form back-guard, motion/accessibility coverage, i18n wording.

> **主题**：界面细节修复批 —— 弹层闭场动效 / 表单返回保护 / 动效与无障碍覆盖 / 多语言文案。

### 修复 · Fixed
- **底部弹层闭场动画**：`ogLShowSheet` 不再自建动画控制器（面板关闭的同帧释放控制器会掐断出场动画），
  改用 `sheetAnimationStyle` 继续按动效档位给时长；档位 0 仍为零时长、直接出现。
- **表单返回保护**：新建发布 / 仓库 / 议题 / Gist / 工作流参数与仓库设置六个表单的
  `PopScope.canPop` 现随输入即时生效 —— 此前输入后按返回仍被当作「未修改」直接放行，
  已输入的内容会被静默丢弃。
- **代码编辑器草稿恢复**：草稿是异步读回的；期间用户已开始输入时，不再用旧草稿
  覆盖当前内容（用户改动优先）。
- **关于页赞助入口**：打不开外部浏览器时先复制仓库链接，再提示「已复制」；
  此前只弹提示、未复制。
- **提示收敛**：设置页 9 处、关于页 2 处散装 `showSnackBar` 统一走 `OgLNotifier`
  （按语义分 success / info / warning）；「取消文件夹授权」改告警语气、
  「下载并发数」改成功语气。

### 变更 · Changed
- 设置页日志区改为 `ExpansionTile`（**默认收起**）：日志随时可能很长，不再常展开撑长页面；
  收起态不构建日志正文。
- 动效覆盖补齐：账户行（`FutureBuilder` 换挡）、日志空态 / 正文加常驻 `AnimatedSize`；
  加速通道增删由通道区外层 `AnimatedSize` 覆盖。
- 无障碍：设置页分组标题补 `Semantics(header: true)`；滑块行加 `MergeSemantics`
  （标题 + 当前值 + 滑块合成一个节点）；色板与加速通道声明 `inMutuallyExclusiveGroup`。
- 动效档位说明与实现对齐：「档位 2 不缩放」更正为「标准档缩放 0.99」，
  `motionStandardDesc` 同步改为「轻微缩放」；「减少动效」说明更正为「手动强制」（档位「静默」直接关闭）。
- 多语言：
  - 冲突提示 8 键（`writeConflict*`）补齐 zh_TW / de / fr / ru 真实翻译；
  - `onboardingLicenseHighlights` 补齐 de / fr / ru（替换仍为英文旧版的整块文案）；
  - 6 语言清除指向**已删内置通道**的表述（`onboarding.json` 许可正文与要点、`settings.json` 私有仓库加速警示）；
  - 德文拼写修正（`Protokdatei` → `Protokolldatei`、`Projektnformationen` → `Projektinformationen`）；
  - 俄文修正（`Не вошедши` → `Вход не выполнен`、`Пубичный` → `Публичный`、`Доступ к всем` → `Доступ ко всем`）。
- 版本号：`pubspec.yaml` 7.3.0+70300 → **7.3.1+70310**；`kOgLAppVersion` 同步升至 7.3.1。
