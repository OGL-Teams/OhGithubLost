本版修复一处导致仓库列表与搜索结果全部为空的问题，新增 GitHub 账号授权登录，并简化首次启动引导。

## 修复

- 仓库列表与搜索结果可能全部为空：较大返回内容的解析结果被误当成异步值，数据取到了却显示不出来。现已恢复正常。
- 网页版写入大文件时的校验计算会失败，现改为在浏览器内直接完成。
- 仓库页切换标签后目录路径被重置；打开文件后返回会回到仓库根目录。现在会停留在原目录。
- 仓库页标签数量随权限加载而变化，导致已切换的标签被弹回第一个。现已保持稳定。
- 删除仓库按钮按管理员权限显示；无权限时说明原因，不再点下去才报错。
- 议题列表的关闭按钮仅对有权限的账号显示。
- 加速通道说明与法律声明中的格式符号不再原样显示，改为正常排版。

## 新增

- 支持使用 GitHub 账号授权登录：在浏览器输入一次性代码即可完成，无需手动创建访问令牌。未配置该方式的版本仍可使用令牌登录。

## 改进

- 首次启动引导由六步精简为三步；引导、权限与登录相关说明整体精简，去掉操作步骤与内部机制的赘述。
- 导航栏与列表的选中项使用主题色，卡片与页面之间的层次更清晰。

## 变更

- 令牌登录与授权登录合并为同一条验证流程，两种方式的行为保持一致。
