**主题 · Theme** — 通知中心、只读缓存、Release 附件交互、动画关闭警告；**并含 4.4.0 未单独发版的修复**。
*Notification centre, read-only cache, Release asset interactions, reduced-motion warning — plus the fixes from 4.4.0 which was never published on its own.*

### 新增 · Added

- **通知中心（R1）· Notification centre (R1)**
  条目可点击展开**完整详情**（时间 / 区域 / 正文，可选中复制）；新增「已读 / 未读」状态与「标记已读 / 全部已读」；保留「重置通知中心」（只清内存条目，磁盘日志不动）。  
  Entries expand to full detail (time / area / body, selectable and copyable); read/unread state with “mark read” and “mark all read” was added; “reset notification centre” remains (clears in-memory entries only, leaving log files untouched).

- **只读端点缓存（R4）· Read-only endpoint cache (R4)**
  中枢级 `GhReadCache` 为 Releases / 分支 / 提交 / Issues / PR / Actions / 仓库详情等只读端点设定 **30–60 秒**缓存，按账号维度隔离；**下拉刷新与写后重读会让缓存失效**并回源；切换账号时清空。搜索、用户、限流端点不缓存；写操作令整体失效。  
  A hub-level `GhReadCache` caches read-only endpoints (releases, branches, commits, issues, PRs, actions, repo detail) for 30–60 s, isolated per account. Pull-to-refresh and post-write reads invalidate and refetch; switching accounts clears the cache. Search, user and rate-limit endpoints are never cached, and any write invalidates the whole cache.

- **Release 附件交互（R5）· Release asset interaction (R5)**
  点击附件改为**查看文件详情**（大小 / 类型 / 下载次数 / 直链），下载与复制链接移到详情弹窗与**长按**菜单，不再点一下就下载。  
  Tapping an asset now opens a detail sheet (size / type / download count / direct link); download and copy-link moved into that sheet and the long-press menu, so a stray tap no longer starts a download.

- **动画关闭警告（R11）· Reduced-motion warning (R11)**
  检测到系统关闭动画（开发者选项 / 无障碍）时，启动即通过通知中心给出**明确警告**（此前应用对此不作任何提示）。  
  When system animations are disabled (developer options / accessibility), a clear warning is surfaced in the notification centre at startup — previously the app said nothing.

### 修复 · Fixed（含 4.4.0 未发版内容 · from unpublished 4.4.0）

- **下载：不再走明文加速通道**。该通道仅支持 HTTP（无 TLS），在 Android 9+ 会被系统直接拦截（`Cleartext HTTP traffic to ... not permitted`）；设置项已从界面移除，通道地址仅存于实现内部常量。  
  Downloads no longer route through the cleartext channel: it only spoke HTTP (no TLS) and Android 9+ blocked it outright. The setting was removed from the UI and the address now lives only as an internal constant.
- **下载完成显示真实大小**：库对小文件可能不发进度事件，界面此前一直显示 `0 B`；现在完成时以磁盘文件大小回填（读不到则按事件码 `OGL-DL-101` 上报）。  
  Completed downloads now show the real size: the library may emit no progress events for small files, which previously left the UI stuck at `0 B`. The size is back-filled from disk on completion, and a failure to read it is reported under event code `OGL-DL-101`.
- **Actions 筛选失效**：成功 / 失败 / 进行中的筛选此前只用于判断空态，列表仍渲染全量；现按筛选后的子集渲染。  
  Actions status filters were only applied to the empty state while the list rendered everything; the list now renders the filtered subset.
- **搜索页切换标签不清空结果**：切「仓库 / 代码」时清空旧结果与输入框。  
  Switching the search tab now clears previous results and the input field.
- **切换 / 移除账号时清空全部缓存**：仓库缓存 + DNS 缓存 + 页面分页快照，避免“用 B 账号看到 A 账号私有数据”。  
  Switching or removing an account now clears all caches (repository cache, DNS cache, paged snapshots) so account B can never see account A’s private data.
- **通知中心打通**：内核诊断的 **warn 与 error** 都会进入通知中心（error → 严重级弹窗，warn → 横幅），且要求携带事件码——不允许静默降级。  
  Kernel diagnostics now reach the notification centre: warnings as banners, errors as blocking dialogs, each required to carry an event code — no silent degradation.

### 已知限制 · Known limitations

- **本版本为预发布（pre-release）**，仅供体验验证。  
  This build is a pre-release, published for early verification.
- 加速通道已从界面移除；**HTTPS 版加速通道将于 4.8.0 重做发布**。  
  The acceleration channel was removed from the UI; an HTTPS version is reworked and released in 4.8.0.
- **多语言（R6）尚未排期**：界面仍为中文。  
  Localisation (R6) is not scheduled yet — the UI is still Chinese.
