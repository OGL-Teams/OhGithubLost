**主题 · Theme** — 内建多线程下载器、统一应用根目录、编辑器草稿、权限与通知中心。
*Built-in multi-threaded downloader, a unified app root, editor drafts, permissions and the notification centre.*

### 新增 · Added

- **内建多线程下载器 · Built-in multi-threaded downloader**
  32 线程分块下载，支持暂停 / 继续 / 取消 / 重试 / 移除；小于 16 MB 的文件一次铺满并发；**服务器不支持 Range 时自动退回单流**。下载管理页展示进度与速率，首页右上角加入口。  
  Chunked downloads across 32 threads with pause/resume/cancel/retry/remove; files under 16 MB saturate concurrency in one go, and servers without Range support automatically fall back to a single stream. The download manager shows progress and speed, reachable from the home app bar.
- **统一应用根目录 · Unified app root**
  根目录固定为 `ogl`：日志落 `ogl/logging`，下载按分类存放。平台路径适配：Android 优先外部可见目录、不可写时退到应用外部目录，桌面用文档目录。  
  Everything lives under `ogl`: logs in `ogl/logging`, downloads sorted by category. Paths adapt per platform — Android prefers a visible external directory and falls back to the app-specific one, desktops use documents.
- **编辑器草稿 · Editor drafts**
  自动保存草稿，再次进入同一文件自动恢复并提醒，提交成功后清除；「我的」页新增草稿箱入口。  
  Drafts save automatically, restore with a notice when the same file is reopened, and clear after a successful commit; the profile page gained a drafts entry.
- **通知中心 · Notification centre**
  首页右上角新增通知中心，可按告警 / 错误筛选、单条复制。  
  A notification centre in the home app bar with alert/error filtering and per-entry copy.
- **分步引导 · Step-by-step onboarding**
  引导改为欢迎 / 权限 / 隐私 / 完成四步。  
  Onboarding is now four steps: welcome, permissions, privacy, done.

### 修复 · Fixed

- 启动接入**失败写入重放**，不再丢启动期的写入。  
  Failed writes during startup are now replayed instead of being lost.
- CNAME 更新改为**加锁写入**，避免并发写覆盖。  
  CNAME updates take a lock so concurrent writes cannot clobber each other.
- 权限网关：Android 存储以**真实写入探针**主动获取，失败弹窗并跳转系统设置。  
  The permission gateway actively probes storage with a real write on Android and, on failure, shows a dialog and opens system settings.

### 已知限制 · Known limitations

- 本版下载器为**自研实现**：后续 4.0.0 已替换为成熟库（`background_downloader`），桌面端下载能力随之变化。  
  This downloader is home-grown; 4.0.0 replaced it with `background_downloader`, which also changed desktop download support.
- Release 附件加速依赖内置代理通道；该通道在 4.3/4.4 起改为设置项并在 4.8.0 以 HTTPS 重做。  
  Accelerated Release downloads relied on the built-in proxy channel, later turned into an opt-in setting (4.3/4.4) and reworked over HTTPS (4.8.0).
- **多语言（R6）尚未开始**：界面为中文。  
  Localisation (R6) has not started yet — the UI is Chinese-only.
