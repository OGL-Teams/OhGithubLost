**主题 · Theme** — 首个稳定版：**展示层全量重写**为 Material 3 直出。
*First stable release: the entire presentation layer was rewritten to emit Material 3 directly.*

### 变更 · Changed

- 展示层全量重写：Material 3 直出，**不再自绘任何框架控件**，相关代码量约 **-55%**。  
  The presentation layer was rewritten to use Material 3 widgets directly, removing every hand-drawn framework control and cutting roughly 55% of that code.
- 文档全量清理；依赖精简（移除 7 个未引用包）。  
  Documentation was cleaned up and dependencies trimmed (seven unused packages removed).
- 质量门（`analyze` + 单元测试）与全平台构建均通过 CI。  
  The quality gate (analyze + unit tests) and the full-platform build matrix both passed in CI.

### 产物 · Artifacts

Android（`arm64-v8a` / `armeabi-v7a` / `x86_64` / `universal` APK / AAB）、Windows、Linux、macOS、iOS —— 共 **19** 个文件。  
Android (arm64-v8a / armeabi-v7a / x86_64 / universal APK / AAB), Windows, Linux, macOS, iOS — 19 files in total.
