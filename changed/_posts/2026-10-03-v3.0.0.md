**主题 · Theme** — 设置页重构、动效档位、关于页、捐赠与开源许可。
*Settings page rebuild, motion levels, an about page, donation and open-source licences.*

### 新增 · Added

- **设置页重构 · Settings rebuild**
  改为**可折叠分组、默认收起**，并补充更多设置项与子项。  
  Rebuilt around collapsible groups that start collapsed, with more settings and sub-items.
- **动效档位设置 · Motion level setting**
  提供「最小 / 当前 / 标准 / 增强」四档，接入页面过渡与减少动效。  
  Four levels (minimal / current / standard / enhanced) wired into page transitions and reduced motion.
- **关于页 · About page**
  整理为设置页内的独立页面：项目名称、主要开发者、版本、仓库地址、未来扩展与启动诊断。  
  Now a standalone page inside Settings: project name, lead developer, version, repository URL, roadmap and boot diagnostics.
- **「捐赠一颗心」· Donate a star**
  二次确认后，用**当前登录账号**为本仓库加星；已 star 时不重复操作。  
  After a confirmation, stars this repository with the signed-in account; a second attempt is a no-op.
- **开源许可与日志栏目 · Licence and log sections**
  「开源许可」列出本项目许可（AGPL-3.0）与第三方依赖；「日志」给日志文件位置与复制入口。  
  The licence section lists the project licence (AGPL-3.0) and third-party dependencies; the log section shows file locations and a copy action.

### 变更 · Changed

- 首页移除**无响应的**刷新按钮，保留下拉刷新。  
  Removed the non-functional refresh button on the home page, keeping pull-to-refresh.
- 写入与删除带**基线校验**：冲突时先提示，再由用户决定是否覆盖。  
  Writes and deletes validate against the baseline SHA and, on conflict, ask the user before overwriting.
- 开源许可切换为 **AGPL-3.0**；新增星标与提交历史图表（见仓库首页）。  
  Switched to AGPL-3.0 and added star/commit history charts to the repository home page.
- 清理部分过时文案。  
  Cleaned up outdated copy.

### 已知限制 · Known limitations

- **多语言仍是骨架**：15 种语言的分片结构自 2.2.0 起存在，但**覆盖面很小**（只有少量已抽取文案）；界面文案的完整本地化在 **4.9.0** 才真正落地。  
  Localisation remains a skeleton: the 15-locale shard structure has existed since 2.2.0 but **covers very little**, and complete UI localisation only landed in **4.9.0**.
- 动效为逐页接入，尚未覆盖全部页面。  
  Motion was wired page by page and does not cover every screen yet.
