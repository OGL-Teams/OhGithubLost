**主题 · Theme** — 下载加速通道重做、文件重命名与目录删除、系统级通知、主题切换动画。
*Download acceleration channels reworked, file rename & directory delete, real system notifications, animated theme switching.*

### 新增 · Added

- **下载加速通道（重做）· Download acceleration channels, reworked**
  独立条目 + 单个总开关 + 通道列表：内置通道（HTTPS，开发者自建）与任意多个自定义通道，**单选生效**；自定义通道可随时移除，内置不可删。  
  A dedicated entry with a single master switch and a channel list: one built-in HTTPS channel plus any number of custom channels, single-select; custom channels can be removed at will, the built-in one cannot.

- **协议与显式同意 · Agreements with explicit consent**
  「外来服务自负责任协议」（自定义通道）与「内置通道安全声明」（内置通道）两份文本，**均带版本号**；未同意当前版本无法开启总开关，同意后记录**版本号 + 时间戳**作为凭据，文本升版需重新同意。  
  Two texts — *Third-party Service Disclaimer* (custom channels) and *Built-in Channel Security Statement* (built-in channel) — each with a version number. The master switch cannot be turned on before consenting to the current version; consent stores version + timestamp as evidence, and a version bump requires re-consenting.

- **文件重命名 · File rename**
  长按文件 → 重命名，内容不变；**一次原子提交**（新增新路径 + 删除旧路径），新路径同样走路径校验；`.gitkeep` 不允许重命名。  
  Long-press a file to rename it without touching its content, performed as one atomic commit (add new path + delete old path). The same path rules apply, and `.gitkeep` cannot be renamed.

- **目录删除 · Directory delete**
  长按目录 → 删除目录：先枚举其下全部文件，再在**一次提交**中删除；结果被截断或超过 200 个文件时**拒绝**并提示分批，不会静默部分删除。  
  Long-press a directory to delete it: all files are enumerated first, then removed in a single commit. If the listing is truncated or exceeds 200 files the operation is refused with a hint to split the batch — never a silent partial delete.

- **系统级通知 · Real system notifications**
  接入 `flutter_local_notifications`：后台与 `allChannels` 通知改为**真正发系统通知**（Android / Windows / Linux / macOS / iOS）；发送失败只留痕，并回退到「落盘 + 回前台补发」。  
  Integrated `flutter_local_notifications`: background and `allChannels` notices are delivered as real system notifications on Android / Windows / Linux / macOS / iOS. Failures are recorded and fall back to “persist + re-deliver on return to foreground”.

- **主题切换动画 · Animated theme switching**
  换明暗 / 换主题色改为动画过渡（`themeAnimationDuration`）；系统关闭动画时自动置 0，与既有规则一致。  
  Switching light/dark or the seed colour is no longer a hard cut (`themeAnimationDuration`). When the system disables animations the duration becomes 0, consistent with existing behaviour.

### 变更 · Changed

- 自定义通道地址**必须是 HTTPS 且以 `/` 结尾**；明文 `http://` 会被直接拒绝并说明原因。  
  Custom channel URLs must be HTTPS and end with `/`; plain `http://` is rejected with an explanation.
- 内置通道地址更新为 **HTTPS**（`https://server.344977.xyz:9999/`）；此前的明文地址会被 Android 9+ 拦截。  
  The built-in channel now uses HTTPS; the previous cleartext address was blocked on Android 9+.
- 生效条件固定为「总开关打开 **且** 已同意当前版本协议」，否则一律直连。  
  Acceleration only takes effect when the switch is on **and** the current agreement is consented to; otherwise downloads always go direct.

### 修复 · Fixed

- 定位并消除 **4.4.0 下载故障的根因**：加速通道只有明文 HTTP，被 Android 9+ 拦截（`Cleartext HTTP traffic not permitted`）——本版改为 HTTPS 后从机制上不再依赖被拦截的传输。  
  Root cause of the 4.4.0 download failure found and removed: the channel only spoke cleartext HTTP and was blocked on Android 9+. With HTTPS in place this class of failure can no longer occur.
- 新增单元测试 `test/surface/path_rules_test.dart`（路径规则 / 空文件 / `.gitkeep` / 通道地址 / 地址拼接 / 协议区分）。  
  Added unit tests covering path rules, empty files, `.gitkeep`, channel URLs, URL joining and agreement selection.

### 已知限制 · Known limitations

- **多语言（R6）尚未落地**：界面仍为中文，已排入 4.9。  
  Localisation (R6) is not shipped yet — the UI is still Chinese; scheduled for 4.9.
- 不支持目录重命名与跨目录批量操作（当前仅单文件重命名 + 目录删除）。  
  No directory rename and no cross-directory batch operations yet (only single-file rename and directory delete).
- 5.0 待办：下载多线程与进度/速度动画、页面过渡卡顿、Actions 长日志加载、通知中心图标与展开动画、安卓返回键统一处理。  
  Planned for 5.0: multi-threaded downloads with progress/speed animation, page-transition jank, long Actions logs, notification-centre icons & expand animation, unified Android back-key handling.
