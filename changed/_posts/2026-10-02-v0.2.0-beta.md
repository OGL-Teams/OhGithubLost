**主题 · Theme** — 第二阶段（W0–W8）：界面与功能重写。
*Stage two (W0–W8): a rewrite of both the interface and the feature set.*

### 新增 · Added（界面 · Interface）

- 统一页面骨架（页头 + 小节 + 箱体行），**12 个页面全部重写**：设置 / 首页 / 搜索 / 我的 / 议题 / PR / 提交 / Gists / 登录向导 / 新建仓库·议题·发布 / 仓库页 / 关于页，全部对齐设计文档（`docs/DESIGN.md`、`docs/UI_SYSTEM_V3.md`）。  
  A unified page skeleton (header + sections + boxed rows) across twelve rewritten pages — settings, home, search, profile, issues, PRs, commits, Gists, sign-in wizard, create flows, repository and about — all following the design docs.
- 主壳导航（手机底栏 / 平板导航轨 / 窄窗抽屉 + 页头）**全部自绘**，与页面同源；图标为 **47 个手写矢量**（零外部资源、纯直线、24 网格），不含任何 Material 字形。  
  The shell navigation (phone bottom bar, tablet rail, narrow-window drawer plus header) is hand-drawn from the same source as the pages; icons are 47 hand-written vectors on a 24-unit grid with straight lines and no external assets or Material glyphs.
- 行控件统一为 `OgLActionRow`（含自绘开关），清掉所有 Material `ListTile` / `SwitchListTile` / `ChoiceChip`。  
  Row controls unified as `OgLActionRow` with a hand-drawn switch, removing every Material `ListTile`, `SwitchListTile` and `ChoiceChip`.

### 新增 · Added（功能 · Features）

- **README 渲染**：仓库页代码标签下显示 README，**离线安全**（徽章行剔除、图片占位、超长截断告知）。  
  **README rendering** under the repository’s Code tab, kept offline-safe: badge lines stripped, images replaced with placeholders, and truncation disclosed.
- **代码搜索直达文件**：搜索结果点开直接打开命中的文件并显示命中上下文。  
  **Code search opens the file**: tapping a result jumps straight to the matching file with context.
- **议题 Markdown**：正文与评论按 Markdown 渲染。  
  **Issue Markdown** for both bodies and comments.
- 提交详情：**分色补丁**预览（+ 绿 / − 红），超长按行截断。  
  Commit details show a colourised patch (green additions, red deletions) with long content truncated per line.
- Gists 整行可点，用浏览器打开；登录向导显示四步进度（暂存 → 验证 → 转正 → 保险库回读）。  
  Gist rows open in the browser; the sign-in wizard shows four visible steps (stage → verify → promote → vault read-back).

### 可靠性 · Reliability

- 空结果不再被当成“加载中”（零议题 / 零发布会显示空态而不是永远转圈）。  
  Empty results are no longer mistaken for loading — zero issues or releases show an empty state instead of spinning forever.
- 404 / 409 / 422 一律当“没有”；不再猜默认分支。  
  404/409/422 are treated as “absent”, and the default branch is never guessed.
- 危险操作全部二次确认；失败一定可见（Banner / SnackBar 摊开 URL / 写日志）。  
  Destructive actions require confirmation, and failures are always visible (banner, snack bar with the full URL, or a log entry).
- 新增**页面纪律护栏测试**：12 个页面必须走统一骨架，禁止 Material 视觉与手写状态判定。  
  Added a page-discipline guard test: all twelve pages must use the shared skeleton, with Material visuals and hand-rolled state checks banned.

### 已知限制 · Known limitations

- **本版本为预发布（pre-release）**：UI 体系在此阶段为自绘，1.0.0 起改为 Material 3 直出。  
  This is a pre-release: the UI system is hand-drawn here and was replaced by direct Material 3 output from 1.0.0 onwards.
- 产物共 **19** 个文件（Android 5 + Windows 2 + Linux 2 + macOS 2 + iOS 2 + 其它）。  
  Nineteen files in total (Android 5 + Windows 2 + Linux 2 + macOS 2 + iOS 2 + others).
