跨平台差异面硬化：把「只在某个系统上才会崩」的隐患逐条改掉，桌面端换成自研窗口，设置页重新分层。
Cross-platform hardening: fixed the "only crashes on one OS" class of bugs, replaced the desktop window chrome with our own, and re-layered the settings page.

## 新增 / Added
- 桌面自绘窗口：自研标题栏（拖拽・双击最大化・最小化/最大化/关闭），可在设置菜单回退系统窗口管理器。
  Custom desktop window: our own title bar (drag / double-click maximize / min / max / close), with a fallback to the system window manager in Settings.
- 桌面图标与原生标题：Windows 生成 256 单帧 ICO，Linux 生成 2048 PNG 母版，原生窗口标题统一为 `OhGithubLost`。
  Desktop icon & native title: Windows gets a single-frame 256 ICO, Linux a 2048 PNG master; native title is `OhGithubLost` everywhere.
- Linux 安装包：`.deb`、`.rpm` 与 `.AppImage`，Release 中裸放直传（不再套压缩包）。
  Linux packages: `.deb`, `.rpm` and `.AppImage`, uploaded raw (no longer wrapped in archives).
- Windows 长路径三层处理：`\\?\` 前缀绕过 → 超限收纳为 `TooLongRoad_<8位>.zip` → 根目录 `.ogl_toolong.json` 索引，读/写/删/列全部可还原。
  Windows long-path handling in three layers: `\\?\` prefix bypass → overflow packed into `TooLongRoad_<8-hex>.zip` → `.ogl_toolong.json` index; read/write/delete/list all round-trip.

## 变更 / Changed
- 设置页重新分层：根级一律取消折叠，严格排序；分类下拉移入二级且默认收起。
  Settings re-layered: no collapsing at the root level, strict ordering; category dropdowns moved to the second level and collapsed by default.
- 赞助入口并入「关于」页。
  The sponsor entry moved into About.

## 修复 / Fixed
- Windows 缓存崩溃：缓存 blob 文件名原样拼接编码键，其中 `|` 是 Windows 非法文件名字符；改为 `sha256(编码键)`。
  Windows cache crash: cache blobs embedded the raw encoded key, and `|` is an illegal filename character on Windows; now `sha256(key)`.
- 设置页退出登录入口重复（危险区已在用户页）。
  Duplicate sign-out entry in Settings (the danger zone already lives in Profile).

## 已知限制 / Known limitations
- **glibc ≥ 2.31**（对应 Ubuntu 20.04 一代及以上；Linux 产物在 `ubuntu:20.04` 容器内构建以锁定该下限）
  - **glibc ≥ 2.31**（对应 Ubuntu 20.04 一代及以上；Linux 产物在 `ubuntu:20.04` 容器内构建以锁定该下限）
- Windows 建议开启长路径支持（非必须，超限有收纳回退）；桌面 32 位、musl、Windows 7 / 8.1 均不支持。
  Windows: enabling long-path support is recommended (not required; overflow has a packed fallback); desktop 32-bit, musl and Windows 7 / 8.1 are unsupported.
