**主题 · Theme** — Release 附件加速改为「设置项 + 默认关闭」；并包含 4.2 线的网络与编辑器重构成果。
*Accelerated Release downloads become an opt-in setting (off by default) — plus the networking and code-editor rework carried over from the 4.2 line.*

### 新增 · Added

- **Release 附件加速改为设置项 · Acceleration as an opt-in setting**
  设置 → 网络 →「Release 附件加速通道」，**默认关闭**：加速通道属于第三方信任边界，必须由用户显式开启；关闭时附件一律直连。该开关只作用于 **Release 附件**，不影响仓库文件 / Gist 下载。  
  Settings → Network → “Release download acceleration”, **off by default**: acceleration crosses a third-party trust boundary, so it must be enabled explicitly; while off, assets are always fetched directly. The switch applies only to Release assets and never to repository files or Gists.

### 变更 · Changed

- **通道地址不再出现在任何界面文案或设置项中**，收敛为实现内部常量。  
  The channel address no longer appears in any UI copy or setting; it lives only as an internal constant.
- 代码查看与编辑换用成熟库：`re_editor`（编辑器内核）+ `re_highlight`（highlight.js 的 Dart 移植），删除自研词法器与自绘渲染 `code_view.dart`；语法高亮、行号、查找替换、撤销重做、折叠与快捷键全部由库提供，光标 / 换行 / 滚动不再错位。查看器与编辑器共用同一套渲染（`OgLCodeViewer` / `OgLCodeField`）。  
  Code viewing and editing moved to established packages: `re_editor` (editor core) plus `re_highlight` (a Dart port of highlight.js), replacing the hand-written lexer and custom renderer. Highlighting, line numbers, find/replace, undo/redo, folding and shortcuts now come from the library, and the caret/line-break/scroll misalignment is gone. Viewer and editor share one rendering path.
- 网络传输弃用 `dio`，改用 `dart:io HttpClient`，并**禁用 keep-alive 复用**（此前连接复用与代理/超时交互不正常）。  
  Networking dropped `dio` for `dart:io HttpClient` with keep-alive reuse disabled, after connection reuse interacted badly with proxies and timeouts.

### 修复 · Fixed

- 本版合入 4.2 线通过设备日志定位的 **P2–P7** 批量修复，并保留项目语义（按扩展名/文件名的语言识别、设置里的高亮预设与自定义配色、草稿防抖落盘、加锁保存与冲突提示）。  
  This release folds in the P2–P7 fixes found via on-device logs along the 4.2 line, while preserving project semantics (language detection by extension/filename, highlight presets and custom colours, debounced draft persistence, locked saves with conflict hints).

### 已知限制 · Known limitations

- **加速通道当前仅支持明文 HTTP**：在 Android 9+ 上会被系统拦截（`Cleartext HTTP traffic not permitted`），因此开启后可能下载失败——请优先保持关闭。此问题已在后续版本修复：4.4.0 临时移除该设置项，4.8.0 以 **HTTPS** 通道重做。  
  The acceleration channel only speaks cleartext HTTP, which Android 9+ blocks (`Cleartext HTTP traffic not permitted`), so enabling it may break downloads — keep it off. Fixed later: the setting was temporarily removed in 4.4.0 and reworked over **HTTPS** in 4.8.0.
- **多语言（R6）尚未开始**：界面为中文。  
  Localisation (R6) has not started yet — the UI is Chinese-only.
