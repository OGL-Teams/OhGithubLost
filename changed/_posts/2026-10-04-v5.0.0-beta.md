> **已被取代 · Superseded**：本 beta 的产物构建于内核一致性硬化之前；
> 请直接使用 **v5.1.0（正式版）** ——它包含本版全部内容 + `OGL-BOOT-108` 交叉校验。
> *These artifacts predate the kernel hardening; use v5.1.0 instead.*

**主题 · Theme** — 交互与体验打磨（不加新功能面）：多连接下载、过渡卡顿修复、长日志虚拟化、通知中心去符号、返回键统一。
*Interaction and feel: multi-connection downloads, transition jank fix, virtualised long logs, emoji-free notification centre, unified back key.*

### 新增 · Added

- **多连接分片下载 · Multi-connection chunked download**
  用 `Range` 请求把文件切成至多 N 片**并发拉取**，最后顺序合并；每片写独立临时文件（规避"共用文件句柄错位写坏"），任一分片失败即删除全部分片——**不交付不完整的文件**。服务端不支持 `Range` 时**自动回退**单连接（同 taskId，页面无感知）。  
  Chunked downloads fetch up to N ranges **in parallel** and merge sequentially. Each part has its own temp file (avoiding the old shared-handle corruption), and any failing part deletes every part — never a half-written file. Servers without `Range` support fall back to a single connection transparently.
- **「下载并发连接数」设置 · Download connections setting**
  设置 → 网络：1 / 2 / 4 / 8（默认 4）；非法值回落默认。  
  Settings → Network: 1 / 2 / 4 / 8, default 4; invalid values fall back to the default.
- **权限自检（每次启动）· Permission self-check on every launch**
  每次启动实测存储（真实写入探针）与通知权限；缺失时以 **warn + 事件码**（`OGL-PERM-001` / `002` / `000`）进通知中心；「关于 → 启动诊断」新增权限自检折叠组。  
  Every launch re-tests storage (real write probe) and notification permissions. Missing ones are reported as **warnings with event codes** through the notification centre; About → boot diagnostics gains a permission self-check section.
- **内核「清单 ↔ 运行期模块」交叉校验 · Manifest coverage cross-check**
  清单声明了某模块、装配时却没提供它 → 记为 `OGL-BOOT-108`（此前会静默放过）。  
  If the manifest declares a module that is never assembled, it is now recorded as `OGL-BOOT-108` (previously silent).

### 变更 · Changed

- **页面过渡改为单层淡入 + 轻位移 · Page transitions rebuilt**
  去掉整页缩放（`ZoomPageTransitionsBuilder` 要求整页反复重新光栅化，正是"只有页面过渡卡"的根因），并强制 `RepaintBoundary`：过渡期间只重合成、不重绘页面内容。  
  Dropped whole-page scaling (the root cause of transition-only jank) in favour of a single fade + slight offset, wrapped in `RepaintBoundary` so transitions only re-composite instead of repainting.
- **Actions 长日志分块虚拟化 · Virtualised long logs**
  按行分块（120 行/块）交给 `ListView.builder` 按需渲染，并显示「共 N 行」。  
  Logs are chunked by line (120 per chunk) and rendered on demand, with a total-line count shown.
- **通知中心去掉 emoji 风格符号 · Emoji-style glyphs removed**
  `✔ / ▶ / ✗ / ★` 等不再出现在用户可见文案里（改由图标与 `level` 承载），详情展开带动画。  
  Symbols like ✔ / ▶ / ✗ / ★ no longer appear in user-visible copy (icons and log levels take over), and detail expansion is animated.
- **安卓返回键统一 · Unified back key**
  二级页 / 弹窗 → 抽屉 → 回首页 tab → 首页第一次提示「再按一次退出」、窗口内第二次才退出；**一次误按不会退出应用**。  
  Nested routes/dialogs → drawer → home tab → on home, first press asks for confirmation and only a second press within the window exits.

### 修复 · Fixed

- 修掉「页面过渡卡顿」根因（见上）。
- 修掉`IxDownloadManager` 在分片任务下的暂停 / 取消 / 重试语义（走取消令牌；不产生错位文件）。
- 修掉通知/日志正文里的符号字形（Android 上会被当 emoji 渲染，即用户报告的"emoji 撕裂"）。

### 已知限制 · Known limitations

- **本版本为 beta 预发布**：请以正式版为准。  
  This is a beta pre-release; prefer a stable build for daily use.
- 分片下载的**暂停 = 重新开始**（不声称续传）；单连接库任务的断点续传不受影响。  
  Pausing a chunked download restarts it rather than resuming; single-connection library tasks keep true resume.
- 桌面端仍使用库下载（分片引擎按 `Range` 能力自动判定，不支持则回退）。  
  Desktop keeps using the library downloader; the chunk engine falls back whenever the server lacks `Range`.

Android (arm64-v8a / armeabi-v7a / x86_64 / universal APK / AAB), Windows, Linux, macOS, iOS plus the signed boot manifest — 19 files in total.
