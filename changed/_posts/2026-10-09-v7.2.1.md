调整平台架构兼容性。

## 变更 / Changed

- **Web 与原生拆分为两个独立系统**：本分支为原生版，只构建 Android / Windows / Linux；
  Web 在独立分支维护，产物发布到该分支的 `app/<版本数字>/`，不产生 GitHub Release。

## 产物 / Artifacts

Android `arm64-v8a` / `armeabi-v7a` / `x86_64` / `universal-APK` / `AAB`、
Windows `x64` / `arm64`、Linux `x64` / `arm64`，每份均含 zip 与 7z。
