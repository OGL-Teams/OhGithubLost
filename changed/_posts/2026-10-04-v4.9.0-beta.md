**主题 · Theme** — 结构与多语言工程（**不含新功能**）：四层依赖收口 + 15 种界面语言落地。
*Architecture and localisation only — no new features: four-layer dependency clean-up plus 15 UI languages.*

### 新增 · Added

- **交互层类型门面 · Surface type facade**
  新增 `lib/surface/types.dart`：UI 只能看到 DTO / 枚举 / 异常，服务类（`GhClient` / `GhAuthService` / `IxDownloadManager` / `IxSession` / `IxNotificationCenter`）被 `hide`，一律经 `SurfaceBridge` 取用；15 个页面 / 组件改为只 import 门面。  
  Added `lib/surface/types.dart`: the UI sees only DTOs, enums and exceptions, while service classes are hidden behind a facade and reached exclusively through `SurfaceBridge`. Fifteen pages/components now import only the facade.

- **下载能力上桥 · Download capabilities on the bridge**
  `SurfaceBridge` 提供 `downloadTasks` / `downloadsListenable` / `pause|resume|retry|cancel|removeDownload` / `clearFinishedDownloads`，下载页不再接触管理器实现。  
  `SurfaceBridge` now exposes task listing, a listenable, pause/resume/retry/cancel/remove and “clear finished”, so the download page never touches the manager implementation.

- **15 种界面语言 · 15 UI languages**
  zh / zh_TW / en / ja / ko / fr / de / es / pt / ru / ar / hi / th / vi / id：**27 个页面 / 848 条中文文案**由人工按语境撰写（GitHub / Release / Actions / PR / Token / Pages 等术语**不译**），其余 14 种语言 AI 按语种合并生成，校验 **15 × 27 / 13065 键，0 问题**。**首次启动跟随系统语言**（繁体系统 → `zh_TW`），设置页即时切换、选择落盘。  
  Chinese copy for 27 pages (848 strings) was authored by hand with terminology deliberately left untranslated; the other 14 locales were generated per-language in a single merged request each and validated with zero issues (15 × 27 pages / 13,065 keys). First launch follows the system language (traditional Chinese systems get `zh_TW`); switching in Settings applies instantly and persists.

- **可执行门禁 · Executable quality gates**
  `tool/layer_audit.py --fatal`（依赖只能 `surface → domain → base → kernel`）与 `tool/i18n_scan.py --check`（界面文案 0 遗漏 / 分片键集合与 zh 一致）已接入 CI；新增维护手册 `docs/I18N.md`。  
  Added to CI: a layer audit (dependencies may only point downwards) and an i18n audit (no unlocalised UI copy; shard key sets identical to the source locale). A maintenance handbook ships as `docs/I18N.md`.

### 变更 · Changed

- 共享抽象上提到 `kernel/contract/`（`disk_store` / `disk_types` / `net_types`，原路径保留转发导出），逻辑层改依赖契约；待收敛项由 11 处降至 **2 处**（仅剩两个实现类）。  
  Shared abstractions moved into `kernel/contract/` with forwarding exports kept at the old paths, and the domain layer now depends on the contracts; outstanding convergence items dropped from 11 to 2 (two implementation classes remain).
- 交互层界面文案 **0 处未本地化**；剩余约 405 处中文均为开发者日志 / 诊断（按设计保留）。  
  There is now zero unlocalised UI copy; the ~405 remaining Chinese strings are developer logs and diagnostics, kept in Chinese by design.

### 已知限制 · Known limitations

- **本版本为预发布（pre-release）**，仅结构与多语言改动，请以稳定版为准。  
  This is a pre-release containing architecture and localisation changes only; prefer a stable build for daily use.
- 翻译由 AI 产出并经过格式与占位符校验，但**未逐条人工校对**；如发现措辞问题请反馈。  
  Translations are AI-produced and validated for structure and placeholders, but not line-by-line human-reviewed; please report wording issues.
- 个别上下文相关文案（如通知正文）可能与实际场景存在细微语感差异。  
  A few context-sensitive strings (e.g. notification bodies) may read slightly off in specific scenarios.
- 5.0 待办：下载多线程与进度/速度动画、页面过渡卡顿、Actions 长日志加载、通知中心图标与展开动画、安卓返回键统一处理。  
  Planned for 5.0: multi-threaded downloads with progress/speed animation, page-transition jank, long Actions logs, notification-centre icons & expand animation, unified Android back-key handling.
