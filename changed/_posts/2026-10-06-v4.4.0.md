## 修复 / Fixed
- **下载不再走明文加速通道**。该通道仅支持 HTTP（无 TLS），在 Android 9+ 会被系统
  直接拦截（`Cleartext HTTP traffic to ... not permitted`）。设置项已从界面移除；
  通道地址仍只存在于实现内部常量，不对外暴露。
  Downloads no longer use the cleartext acceleration channel, which Android 9+ blocks
  outright. The setting was removed from the UI.
- **下载完成显示真实大小**：库对小文件可能一次进度事件都不发，此前界面一直显示
  `0 B`；现于完成时以磁盘文件大小回填（读不到则按事件码 `OGL-DL-101` 上报）。
  Completed downloads now back-fill the real file size instead of showing `0 B`.
- **Actions 筛选失效**：成功 / 失败 / 进行中筛选此前只用于判断空态，列表仍渲染全量；
  现按筛选后的子集渲染。
  The Actions status filter had only affected the empty state; the list now renders
  the filtered subset.
- **搜索页切换标签不清空结果**：切「仓库 / 代码」时清空旧结果与输入框。
  Switching tabs on the search page now clears stale results and the input.
- **切换 / 移除账号时清空全部缓存**：仓库缓存 + DNS 缓存 + 页面分页快照
  （避免"用 B 账号看到 A 账号的私有数据"）。
  Switching or removing an account now clears all caches — repository cache, DNS
  cache and page pagination snapshots — preventing cross-account leakage.
- **通知中心打通**：内核诊断的 **warn 与 error** 现在都会进入通知中心
  （error → 严重级弹窗；warn → 横幅），且要求携带事件码 —— 不允许静默降级。
  Kernel diagnostics (warn and error) now reach the notification centre, and an
  event code is mandatory — silent degradation is not allowed.

## 已知限制 / Known limitations
- 本版**未发布**，无产物可下载；需要安装的用户请取 **v4.6.0** 或更新版本的产物。
- macOS / iOS 在后续版本（v5.6.0 起）已弃用。
