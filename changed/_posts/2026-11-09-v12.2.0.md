本版上线 GitHub 账号授权登录，并修复浏览、下载与账户链路中的一批安全与可靠性问题。

## 新增

- 使用 GitHub 账号授权登录：登录页显示一次性代码与官方授权页地址，确认应用归属与权限范围后完成登录；访问令牌仅保存在本机安全存储，退出登录即删除。未配置授权的版本自动隐藏该入口，个人访问令牌登录不受影响。
- 启动时校验账号令牌是否仍在本机：令牌缺失时直接进入登录门，不再以未登录身份发起注定失败的请求。
- 账号信息损坏时改为隔离并提醒，登录凭据保留可排查，不再静默删除。

## 改进

- 界面字体下载后保存到本机，再次启动无需重复下载；所选字体未能生效时会记录原因，便于排查。
- 界面各处文字样式统一跟随所选界面字体；登录状态变化的通知不再重复触发。

## 修复

- 私有仓库的图片预览不再经由第三方加速通道：此前浏览私有仓库时每张图片都会把访问令牌发送给通道服务器，且无任何确认与记录；现已改为直连官方地址。
- 议题的锁定功能此前请求方式与服务端不符导致不可用，现已更正。
- 下载入口在私有仓库加速时会跳过令牌出设备的确认警告，现已与其它下载入口一致。
- 列表类接口收到格式异常的响应时不再静默显示为「暂无数据」，而是如实报错。
- 下载重试落在已移除的任务上时不再毫无反馈；文件完整性校验区分「文件丢失」与「内容不匹配」。

## 说明

- 本应用使用 GitHub 设备流授权，全程不需要 Client Secret；应用也绝不收集或请求该凭证。
- 建议配置加速通道时知悉：开启私有内容加速意味着相应请求会经过该通道服务器，应用内已有不可关闭的警告与记录。
