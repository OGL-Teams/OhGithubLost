**主题 · Theme** — 仓库浏览能力补齐 + 控件与布局的 Material 3 规范化。
*Rounding out repository browsing and normalising controls/layout on Material 3.*

### 新增 · Added

- **分支切换 · Branch switching**
  AppBar 下方常驻分支栏（Material 底部弹层 + 搜索），切换后「代码 / 提交 / 发布 / Actions」同步。  
  A persistent branch bar under the app bar (Material sheet with search); switching it keeps the Code / Commits / Releases / Actions tabs in sync.
- **新建文件 · Create file**
  代码标签提供 `FloatingActionButton` 入口（路径 + 内容）。  
  The Code tab offers a `FloatingActionButton` entry with path and content fields.
- **目录内筛选 · In-directory filter**
  按名称过滤当前目录条目。  
  Filters the current directory’s entries by name.
- **图片预览 · Image preview**
  png / jpg / jpeg / gif / webp / bmp / ico 在应用内预览（可缩放），不再显示为二进制内容。  
  png, jpg, jpeg, gif, webp, bmp and ico preview in-app with zoom instead of raw binary output.
- **分页「加载更多」· Pagination (“load more”)**
  首页仓库列表（我的 / 星标）与仓库页的发布 / 分支 / 提交 / Actions 统一分页；`GhApi.workflowRuns` 新增 `branch` / `page` 参数。  
  Pagination unified across the home repository lists (mine / starred) and the repository page’s releases, branches, commits and Actions; `GhApi.workflowRuns` gained `branch` and `page` parameters.

### 变更 · Changed

- **主操作统一为 `FloatingActionButton.extended`**：新建仓库 / 议题 / 发布 / 分支 / 文件。  
  Primary create actions now use `FloatingActionButton.extended` consistently (repository, issue, release, branch, file).
- **次要操作收进 `PopupMenuButton`**：仓库（复刻 / 复制克隆地址 / 浏览器打开）、文件（复制路径 / 浏览器打开 / 删除）、分支（重命名 / 删除）。  
  Secondary actions moved into `PopupMenuButton` menus: repository (fork / copy clone URL / open in browser), file (copy path / open in browser / delete), branch (rename / delete).
- 空 / 错 / 载三态与「加载更多」底部按钮统一；列表项统一 `ListTile` + `OgLReveal`。  
  Empty/error/loading states and the “load more” footer are now consistent, and list rows use `ListTile` + `OgLReveal`.
- **危险操作统一二次确认**：删除文件 / 分支 / 仓库。  
  Destructive actions (delete file, branch, repository) all require a confirmation step.

### 已知限制 · Known limitations

- **本版本为预发布（pre-release）**：其成果随后并入 **4.3.0** 正式版。  
  This is a pre-release whose work was folded into **4.3.0**.
- 分支切换只作用于上述标签；议题 / PR 列表仍是仓库级（相关接口不按分支过滤）。  
  Branch switching applies to the tabs above only; issue and PR lists remain repository-level because the API does not filter them by branch.
- 代码标签的目录内容由 Contents API 一次性返回，「加载更多」在代码标签只表现为一次拉取。  
  Directory content in the Code tab comes from a single Contents API call, so “load more” performs one fetch there.
- 文件内查找、blame、以及图片以外的二进制预览仍未实现。  
  In-file search, blame, and binary previews beyond images are still missing.
