本版调整发布范围：网页版转为独立维护，本版本专注移动端与桌面端，并补齐各平台的安装包规格。

## 变更

- 网页版不再随本版本一同发布，改由单独的渠道持续维护。浏览器中的使用方式、账号与数据均保留在该渠道内，与本地安装的版本互不影响。
- 本版本仅提供 Android、Windows 与 Linux 三个平台的安装包。macOS 与 iOS 的安装包不在本次发布范围内，相关平台的用户暂不适用本版本。
- Android 安装包覆盖主流处理器架构，并额外提供通用安装包。不确定设备架构时，可直接选用通用安装包完成安装。
- Windows 与 Linux 各自提供 64 位与 ARM 架构两种安装包，每种均含常用压缩格式，便于在不同环境下解压或直接运行。
- 三个平台的安装包在功能上完全一致，不因平台差异删减能力。此后的更新按平台分别发布，某一平台的更新节奏不影响其他平台。
- 两端的更新不再同步进行，界面细节与功能可能出现时间差；以各渠道当次发布的说明为准。

- 各平台安装包按处理器架构分列，同一平台内可对照设备选择，减少因选错安装包而无法安装的情况。
- 压缩格式提供两种常见形式，缺少对应解压工具时仍可直接使用，无需另行安装。
