本版移除 AI 助手，界面语言收敛为简体中文与 English，并集中修复文件编辑与提交中的数据安全问题。

## 移除

- 移除 AI 对话、AI 设置、模型配置与相关入口。
- 升级时清理本机遗留的 AI 密钥、会话与操作记录，不影响 GitHub 账号与仓库内容。
- 界面语言仅保留简体中文与 English。

## 修复

- 从文件列表进入编辑器前重新读取完整文件，避免把目录摘要或空内容写回原文件。
- 不支持 UTF-8 的文件不再进入可保存的编辑流程，防止编码转换破坏原始内容。
- 恢复草稿时沿用起草时的版本基线，远端已变化时仍会进入冲突检查。
- 草稿的保存与删除按文件顺序执行，旧写入不再覆盖新内容，也不会让已提交内容重新出现。
- 文件名包含 `#`、`?` 等字符时，读取、保存与删除均使用正确路径。
- 删除文件时校验用户确认的版本，避免误删之后出现的新版本。

## 改进

- 校正中英文案，修正英文设置页中内容错位的条目。
- 普通错误提示不再展示异常类型、堆栈或内部路径。
- 放弃修改确认、对话框与提示方式统一遵循全局界面规范。
- 保存成功、远端冲突与本地清理的结果分别呈现，不再误报提交失败。
