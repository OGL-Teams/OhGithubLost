新增全屏代码编辑与完整的发布管理，Actions 可手动触发工作流，并引入多语言界面。

## 新增

- 全屏代码编辑器支持撤销与重做、查找与替换、自动换行与字号调整；有未保存修改时离开会被提示，保存前可预览高亮效果。
- 发布管理补齐资产列表与下载、编辑标签标题与说明、草稿与预发布标记、删除以及复制发布说明。
- Actions 支持手动触发工作流，可选择工作流、分支与参数；运行详情显示每个作业与步骤的状态、结论与耗时。
- 设置页新增语言分组，可选择界面语言，切换后立即生效。
- 界面语言支持繁体中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语、俄语、阿拉伯语、印地语、泰语、越南语与印尼语。

## 改进

- 文件与目录读取加入短时缓存，可手动刷新；写入与删除前会核对内容是否已被他人改动，过期则拒绝并提示。
- 系统长按菜单中的复制、粘贴与全选改为中文。
- 设置页改为可折叠分组，项目较多时更易定位。

## 变更

- 多语言目前仅覆盖少量界面文案，其余内容仍以中文显示，完整翻译在后续版本陆续补充。
- 中文界面中的 GitHub 术语保留英文写法，如 Issues、Releases、Actions 与 Pull Requests。
- 切换语言无需重启，选择会保存在本机；尚未翻译的条目回退为英文显示。
