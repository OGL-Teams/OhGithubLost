取消内置加速通道，加速范围改为按资源类型逐项选择，并修正审查中发现的多处问题。

## 变更

- 移除内置加速通道与内置镜像，通道列表不再包含任何预置项；需要加速时自行添加通道地址，不添加则始终直连。
- 加速范围改为四类开关：发布附件、构建产物、仓库文件（下载与预览）、README 仓库内图片，默认全部开启，可逐项关闭。
- 取消失败后的静默降级：界面显示正在加速时即确实经过通道，失败会明确报错，不再悄悄改走直连。
- 使用条款升版并要求重新同意，正文写明本应用不预置通道、不提供代理服务。
- Action 运行日志不参与加速，始终直接获取。

## 修复

- 私有仓库的 README 图片此前返回找不到文件，现可正常显示。
- 不同仓库中的同名图片可能互相串用，现按仓库与分支分别读取。
- 分页列表在已缓存时只显示第一页，现可继续翻页。
- 同一文件第二次下载时不再复制到所选文件夹的问题修正。
- 自定义域名解析与加密解析开关对实际请求不生效的问题修正。
- 切换账号后仍可能看到上一个账号的内容，现会清除全部缓存。
- 已移除的下载任务重新出现在列表、合并失败残留不完整文件的问题一并修正。
- 设置页、仓库页与关于页共十九处文案显示为内部键名，现均显示正常译文。
