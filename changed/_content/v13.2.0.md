本版按品牌与文案规范重写了项目自述文档，并改进了授权登录方式。这是 v14 正式版前的第二个 beta 预发布版本。

## 登录

- 授权登录改用浏览器授权：点击「授权登录」后自动打开浏览器，登录 GitHub 并点一次 Continue 即完成，无需抄写设备码，也无需等待轮询。
- 授权基于 OAuth App 网页流程与本地回环回调：令牌仍只保存在本机保险库，客户端不接触任何密钥。
- 若浏览器授权不可用（如网页版环境），自动回落到原有的设备码方式；经典令牌登录不受影响。
- 此前部分用户反馈授权登录隔日失效。经排查，令牌本身没有有效期，失效源于设备码轮询链路不稳；新的网页授权一次跳转完成，不再经过该链路。

## 自述文档

- 中文与英文自述文档按品牌文案规范重写：首屏三行内说清项目定位、适用人群与核心取舍；贡献条款、致谢名单、平台矩阵、下载入口等事实内容逐项保全。
- 中英两版章节一一对应，链接集合完全一致。

## 检查

- 十一支门禁与元验证通过；界面文案键集合、键顺序与占位符零差异。
- 类型检查与单元测试由持续集成裁决通过。

## 预发布说明

- 本版本为 beta 预发布，供提前验证登录改进与文档变更，不作为稳定版推荐使用；正式发布随 v14 稳定版到来。
