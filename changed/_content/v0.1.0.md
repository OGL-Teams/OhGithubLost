首个公开版本，提供从登录到仓库日常操作的完整能力，覆盖代码浏览、议题、Pull Request 与发布管理。

## 新增

- 支持使用个人访问令牌登录，按引导完成验证即可使用；同时提供游客模式，未登录也可浏览公开内容。
- 首页集中展示我的仓库与星标仓库，并可直接新建仓库。
- 搜索同时覆盖仓库与代码，代码结果可定位到命中的文件。
- 仓库内可浏览文件、编辑并提交改动；议题支持新建、评论与关闭；Pull Request 可查看列表与涉及的文件。
- 新建发布时可填写标签、标题与说明；分支可增加、删除与重命名；提交历史可查看改动概览，并对比任意两次提交。
- 仓库设置内可调整站点发布、自定义域名与危险操作区域。
- 附带 Gist 列表、多账号管理、网络与 DNS 设置以及应用日志查看。

## 变更

- 安装包统一使用固定签名证书，此后各版本可直接覆盖升级。
- 由此前构建安装的应用无法直接覆盖，需先卸载再安装本版本。
- 卸载会清除本机保存的登录信息，重新安装后需要再次登录。
