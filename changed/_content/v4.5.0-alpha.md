通知中心与只读页面的使用体验在本版集中完善，Release 附件的交互方式重新设计，并修复了下载、筛选与账号隔离方面的多处问题。

## 新增

- 通知条目可展开查看时间、区域与完整正文，正文文字可选中复制。
- 通知新增已读与未读状态，可逐条标记，也可一键全部标为已读。
- 点击 Release 附件先打开详情，显示大小、类型、下载次数与直链；下载与复制链接移至详情窗口与长按菜单。
- 发布、分支、提交、议题、拉取请求、Actions 与仓库详情等只读页面，在短时间内重复打开时直接显示已有内容，不再重复等待。

## 改进

- 重置通知中心只清除当前列表，已保存的记录不受影响。
- 系统关闭动画时，应用启动后会在通知中心给出明确提示，不再没有任何说明。
- 诊断中的警告与错误都会进入通知中心，错误以弹窗呈现，警告以横幅呈现，不再有静默降级。
- 搜索页在仓库与代码之间切换标签时清空旧结果与输入内容，避免沿用上一个标签的内容。

## 修复

- 下载此前会经过仅支持明文传输的加速通道，在较新的 Android 系统上被系统拦截并失败；该通道已从界面移除。
- 小文件下载完成后此前一直显示 0 B，现显示磁盘上的实际大小。
- Actions 的成功、失败与进行中筛选此前只影响空状态判断，列表仍显示全部内容，现按筛选结果呈现。
- 切换或移除账号时清理全部已保存内容，不再出现账号之间的数据混淆。
- 通知正文与日志中的特殊符号不再被系统当作表情符号渲染。

## 变更

- Release 附件加速设置已从界面移除，附件一律直连获取。
- 已取回的内容在有效期内可能不是最新，下拉刷新可立即更新。
- 界面仍只提供中文。
