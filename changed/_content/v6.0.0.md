桌面端换用自绘窗口，设置页重新分层，并修正仓库浏览中的多处问题。

## 新增

- 桌面端采用自绘标题栏，支持拖拽移动、双击最大化以及最小化、最大化、关闭，可在设置中回退到系统窗口。
- Linux 提供 deb、rpm 与 AppImage 三种安装包，下载后可直接安装使用。
- 桌面图标与窗口标题统一：Windows 使用单帧图标，Linux 使用高分辨率母版，窗口标题在各平台保持一致。
- Windows 上遇到超长路径时自动收纳，并在读取、写入、删除与列表中完整还原，无需手动改名。

## 改进

- 设置页重新分层：根级项目不再折叠并按固定顺序排列，分类选项移入下一级且默认收起，常用设置更容易找到。
- 赞助入口移入关于页，设置页结构更为集中。
- README 图片可以正常显示，以 HTML 写法插入的图片同样有效；单次最多显示四十张，加载失败时改为显示替代文字。

## 修复

- Windows 上因缓存文件名包含非法字符导致的崩溃已修正。
- README 中的相对链接、页面内锚点与裸域名可以正常打开，无法解析时给出提示而不是毫无反应。
- 设置页中重复的退出登录入口已移除，退出登录统一在个人页的危险操作区。

## 变更

- 桌面端窗口标题统一为 OhGithubLost。
- Linux 安装包在发布页直接提供，不再额外套一层压缩包。
- 建议 Windows 开启系统长路径支持；未开启时由应用自动收纳超长路径。
