# 更新日志

OhGithubLost（简称 OGL）是一款 GitHub 仓库管理客户端，支持手机、平板和电脑。这里按版本顺序记录每次发布的变化，并提供各版本的安装包下载。

## 支持的平台

| 平台 | 说明 |
| --- | --- |
| Android | 手机与平板，提供 4 种 CPU 架构的安装包 |
| Windows | 电脑，x64 与 ARM 两种 |
| Linux | 电脑，x64 与 ARM 两种 |
| macOS / iOS | 已停止维护，最后支持版本为 v5.3.0 |

## 如何选择安装包

- **Android**：不确定手机型号时，下载 `universal` 通用包即可，可覆盖绝大多数设备。
- **Windows / Linux**：多数电脑选择 `x64`；若设备为 ARM 架构（如骁龙 Windows 本、部分 Apple 芯片设备），选择 `arm64`。
- 每个安装包都提供 `.zip` 与 `.7z` 两种压缩格式，任选其一解压即可。

## 关于版本号

- `6.0.0` 这类纯数字版本为正式版，可放心使用。
- 带 `-beta` 或 `-alpha` 后缀的为测试版，功能可能尚未完整，建议仅在尝鲜时使用。

## 遇到问题

- 安装后无法启动：请先卸载同包名的旧版本，再安装新版本。
- Linux 无法安装：请确认系统为 Ubuntu 22.04 或更新版本。
- 其他问题：请前往[项目 Issues](https://github.com/OGL-Teams/OhGithubLost/issues) 反馈。
