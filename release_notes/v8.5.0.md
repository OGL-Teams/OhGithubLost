# v8.5.0（2026-10-15 · 正式版）

> **主题**：AI 配置可用性修复 · 下载管理增强 · Web 分支编译彻底修通 · 统计图表 5K 极客风。

---

## 新增 · Added

### 下载管理：一键重试 + 撤销移除
- 失败/取消的任务不再需要逐条点「重试」，顶栏新增「重试全部失败」，一次重来所有失败项。
- 移除任务后顶部出现「撤销移除」条，点一下把刚移除的任务放回列表（误触可反悔）。

### 统计图表：5K 极客风 + 算法加固
- 图表分辨率提升到 **5K（5120×2880）**，暗色终端配色 + 霓虹青/磷光绿系列色，
  保留像素字体但重排布局（HUD 头栏 / 四角终括号 / 十字准星标当前值）。
- 横轴固定 10 个均匀刻度、纵轴自动 10 个刻度；折线**单调三次平滑**（不过冲）。
- 修复一批边界缺陷：无穷大/NaN 不再死循环或抛异常、超大数用 K/M 紧凑记数、
  时间标签抽稀不再重叠、PNG 改原子写（磁盘满不会留半张坏图）。
- 渲染性能提升约 **3.7 倍**（单图 46.8s → 12.5s）。

## 修复 · Fixed（修复前 → 修复后）

### AI 配置 HTTP 端点崩溃
- **修复前**：AI 设置里填以 `http://` 开头的端点（本机/内网常见的 Ollama、one-api 等），
  应用直接崩掉并弹未捕获异常，用户完全不知道错在哪。
- **修复后**：`http` 与 `https` 都可用；输入框即时校验收据（地址非法、带用户名密码、
  带 ?参数 都会立刻红字提示）；明文 `http` 会显示「同网络设备可见」的知情提示，
  但**不阻止使用**。

### AI 底层错误未捕获（TLS 握手等）
- **修复前**：自签证书握手失败、密钥存储（Keystore）异常等**非业务异常**一路穿透，
  表现为「点保存/检测模型毫无反应」。
- **修复后**：传输层补 `IOException` 兜底、设置页三处补宽泛 catch，任何失败都
  落到可见的错误提示，不再有静默的未捕获异步错误。

### 下载「完成却卡在下载中」
- **修复前**：完整性校验清理坏文件时若抛错，任务状态永远停在「下载中」。
- **修复后**：下载收尾加顶层兜底，异常时如实标记「失败」并留诊断日志。

### Web 版长期无法构建
- **修复前**：Web 分支自 v7.x 起持续构建失败——`package:http` 未声明、
  `isolate_manager` 依赖链拖入 `dart:html`（dart2wasm 不支持）、
  `window_manager` 把 `dart:io` 拖进主链路。
- **修复后**：补依赖声明 + 依赖覆盖 + 平台隔离壳，Web（wasm + js）双构建首次成功，
  Netlify 站点正常上线。

### 剪贴板静默失效（残留点）
- **修复前**：外链打开失败、下载路径复制等场景仍在部分页面直接调平台剪贴板，
  Web 端无用户手势时静默失败。
- **修复后**：全部走统一封装 `ogLCopyText`，失败可见。
