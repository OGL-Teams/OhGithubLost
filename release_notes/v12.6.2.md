# v12.6.2

> **请以本版为准**：v12.6.1 已发布但含一处重名覆盖的已知问题，
> 本版修复该问题与继续下载的分片回归。v12.6.1 的发布产物保留作历史，
> 不建议安装。

## 修复

- **重名重试路径复用**：上一版只记住「同一任务重试」这件事，没有记住上一轮裁决后的落盘路径。若已有 `a.zip`，下载会裁决为 `a (1).zip`；此时移除任务再下载，旧版会退回 `a.zip` 覆盖用户原文件。本版直接复用上一轮裁决后的路径与文件名，数据无价，不再覆盖已有文件。
- **继续下载的分片守卫**：继续一个普通单连接任务时，旧版会误启多线程分片并从头重下。现在只有原本就在跑分片的任务才重启分片引擎，其余任务继续走下载库的断点续传。
- 承接 v12.6.1 的域名解析结果过滤：建立连接前拒绝私网、回环、链路本地与云元数据地址，全部被拦时如实报错。

## 改进

- 重名裁决的页面显示、任务描述与落盘路径三者一致已扩到「移除后再下载」与「从分片回退单连接」两条分支。
- 补充源码约束，防止重名重试退回原路径、普通任务误启分片再次潜入。

## 已知限制

- 域名解析回退状态目前仅写入内部诊断，尚未在界面呈现。
- 第三方下载库内部的跨主机跳转仍属已知暴露面；签名地址失败时已强制走直连并给出令牌出设备警告。

## 产物

- Android（arm64-v8a / armeabi-v7a / x86_64 / universal APK / AAB）、Windows（x64 / arm64）、Linux（x64 / arm64），每份提供 zip 与 7z 双格式，共 23 件。
- macOS / iOS 自 v5.6.0 起不再提供。
