# v14.0.0

本版是 v13 系列四步迭代的正式版：界面语言扩展至 30 种，授权登录改为浏览器一次授权，界面文案与项目文档按专业规范全面重写，并新增语义色对比度门禁。
This is the stable release of the four-step v13 iteration: interface languages expanded to 30, authorization sign-in moves to one-press browser flow, interface copy and project documentation are professionally rewritten, and a semantic-color contrast gate is added.

## 登录 / Sign-in

- 授权登录改用**浏览器授权**（OAuth App 网页流程 + 本地回环回调）：点击「授权登录」打开浏览器，点一次 Continue 即完成；无设备码、无轮询。浏览器授权不可用时自动回落设备码方式；经典令牌登录不受影响。令牌仍只存本机保险库。
  Authorization sign-in now uses browser-based authorization (OAuth App web flow with a local loopback callback): one Continue press completes sign-in, with no device code and no polling. The device-code flow remains as fallback; classic token sign-in is unchanged. Tokens remain in the on-device vault.

## 界面语言 / Interface Languages

- 30 种界面语言全部接入，每种覆盖全部 28 个页面分片、1272 个键；法律与声明正文逐句翻译。
  All 30 interface languages ship with complete coverage — 28 page shards and 1272 keys each; legal texts translated sentence by sentence.
- 界面文案按 UX 写作规范重写并同步到全部语言：错误消息写明后果与可逆性、空态给出下一步、按钮标签动词式。
  Interface copy is rewritten to UX-writing standards and synchronized across languages: errors state consequences and reversibility, empty states guide next steps, buttons use verb-first labels.

## 文档 / Documentation

- 中文与英文自述文档按品牌文案规范重写，事实内容逐项保全、链接集合一致。
  Both READMEs are rewritten to brand standards with facts preserved and identical link sets.
- 技术文档按 Diátaxis 架构重组，索引逐篇标注类型与状态。
  Technical documentation is reorganized by Diátaxis with a typed, status-marked index.

## 设计与检查 / Design and Verification

- 全面执行 Material 3：主题字号从文本主题派生、动态取色（Material You）、触控目标 48dp、断点对齐规范、修后审计 97/100。
  Full Material 3 execution: theme typography derived from the text theme, dynamic color (Material You), 48dp touch targets, spec-aligned breakpoints, post-fix audit 97/100.
- 新增**语义色对比度门禁**（12 支门禁之一，WCAG 2.1 正文 4.5:1 / 图形 3.0:1）；十二支门禁与元验证全部通过；类型检查与单元测试由持续集成裁决。
  A semantic-color contrast gate is added (twelfth of twelve; WCAG 2.1 4.5:1 text / 3.0:1 graphics); all twelve gates and meta-verification pass; type analysis and unit tests are judged by continuous integration.

## 兼容性 / Compatibility

- 首次启动按设备语言选择界面语言；既有配置与数据不受影响，v13 各版本的修复全部保留。
  First launch selects the interface language from the device locale; existing configuration and data are unaffected, and all v13 fixes remain intact.
