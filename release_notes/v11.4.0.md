# v11.4.0

## 新增

- 网络设置中的自定义解析服务地址更安全：不再接受指向内网、本机回环或云元数据地址的解析器；解析结果的私网地址一律丢弃。
- 下载管理新增周期性清理：超过数量上限或保存时长的旧缓存会自动淘汰，不再无限占用磁盘。

## 改进

- 大文件下载更可靠：分片规划保证每一片不小于既定大小；各分片返回内容必须与请求区间逐字节对齐，错位或被改写的响应一律拒绝；单一分片失败不再影响其它分片的收尾清理。
- 探测下载方式失败时，会在日志中记录真实原因，不再一律显示为「服务端不支持」。
- 网络不稳时，切换下载通道同样遵守服务端的等待要求，不再连续冲击多个地址。
- 更换自定义解析服务后立即生效，不再沿用旧的解析结果。
- 设置页文案精简；说明文档与实际行为保持一致。

## 修复

- 部分情况下解析结果可能来自错误域名的应答，现已按查询域名过滤。
- 网络请求的超时时间此前忽略调用方设置，现按各请求设定生效。
- 保存冲突后自动重试时，若无法确认远端最新版本，将明确失败并保留内容，绝不盲写覆盖他人提交。
- 特定长路径下，本地缓存的读取失败不再被当作「文件不存在」，避免相关数据被误清。
