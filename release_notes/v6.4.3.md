# OhGithubLost v6.4.3

删掉内置代理，只留自定义通道；加速适用范围改为**逐项可选**；去掉静默降级。
Built-in proxies removed; acceleration scope is now opt-in per resource kind; no silent fallback.

## 新增 / Added

- **加速适用范围可逐项开关**（设置 → 网络 → 加速）。前缀式代理开放的端点有限 ——
  有的能转发 Release 附件，却转发不了仓库内图片；把"哪些资源加速"写死，无法覆盖不同通道的能力差异。现在由你自己指定，**只有 4 类**：

  | 开关 | 覆盖的资源 |
  | --- | --- |
  | Release 附件 | 发布页附件下载 |
  | Action 构建产物 | 运行详情页的产物下载 |
  | 仓库文件（下载与预览） | 仓库页下载、预览页「加入下载」与大文件取法 |
  | README 仓库内图片 | 仓库页与子目录页的 README 图片 |

  默认全开（与旧版行为一致），可逐项关掉；全部关掉也合法（等于不加速）。
  **Action 运行日志不在此列** —— 它从不走加速。

## 变更 / Changed

- **协议升版 v3 → v4，需要重新同意**：正文重写 —— 删去「本应用提供 / 维护通道」的
  表述，明确「本应用不预置任何通道，也不提供代理服务」，并把「失败不静默回落直连」
  写进条款。

## 移除 / Removed

- **内置加速通道**（原 `proxy.344977.xyz`）：通道列表不再含内置项，要加速请自行添加。
  内置通道是一台由项目维护的代理服务器 —— 无论协议怎么写，它都在信任链上：它知道你
  请求了什么文件，也能在签名地址有效期内自行取走文件。这与本项目"本地工具"的定位冲突。
- **内置网络镜像**（原 `ghproxy.net` 换主机规则）：同样是"我们替你选的第三方代理"，
  已清空。
- **降级回退**：加速判定现在**至多给一项** —— 加速就是 `前缀 + 原址`，不加速就是原址，
  **不再垫一个直连候选**。此后不会出现「界面显示在加速、实际走的直连」这种状态：失败即报错。多前缀的「优先级链」也一并删除。

## 修复 / Fixed

- 设置页「添加自定义通道」的副标题此前是**硬编码中文**，未走 i18n；6 语言补齐。
- `i18n_scan.py` 的失效豁免（内置通道展示名）已清除，并记录其 UI/日志分类跨度过宽的
  已知盲区。

## 已知限制 / Known limitations

- **web（浏览器）端**：私有仓库的 raw 与「私有 + 加速」都不可用 —— 浏览器预检会拦住
  `Authorization` 头，而 Release 附件的签名地址不带 CORS 头，脚本读不到。详见
  [`docs/NETWORK.md`](https://github.com/OGL-Teams/OhGithubLost/blob/main/docs/NETWORK.md)。
- **音频不做内置播放**：Contents API 对超过 1 MB 的文件不返回内容。
- **Linux 裸放安装包 3 / 6**：rpm（arm64）缺平台定义；AppImage 的 `ARCH` 环境变量未被接受。
  三种包在 zip / 7z 里都齐全。
- macOS / iOS 自 v5.6.0 起弃用。
