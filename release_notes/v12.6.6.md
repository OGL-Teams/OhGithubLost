# v12.6.6

## 设置页

- **单层进入式重构**：根页只保留账户、界面、代码与文件、存储与网络、关于、日志、危险操作七个分类入口；点入子页后才显示可折叠分组，子页内分组默认展开，仍可手动收起。根页不再平铺长列表与折叠组。
- **文案精简**：六语言设置文案全面改短，根页可见的标题与摘要都压缩为一句话；新增两个简短摘要键并补齐六语言。
- **关于页去占位**：删除「未来扩展 / 贡献者名单 / 致谢」整张占位卡片及六语言占位文案；没有真实内容的项目不再占屏幕。启动诊断、权限自检、开源许可全文、法律文本与捐赠入口均为既有真实功能。

## 说明

- 设置项的功能与持久化行为不变，只调整层级结构与呈现。
- 前版的架构、下载、域名解析与质量门禁修复保持不变。
- 新增回归锁：根页不得再出现折叠组，所有分类必须经入口进入；关于页不得再出现占位文案。

- Android（arm64-v8a / armeabi-v7a / x86_64 / universal APK / AAB）、Windows（x64 / arm64）、Linux（x64 / arm64），每份提供 zip 与 7z 双格式，共 23 件。
- macOS / iOS 自 v5.6.0 起不再提供。
