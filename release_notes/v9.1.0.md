# v9.1.0（2026-10-15 · 正式版）

> **主题**：9.0 后的用户体验/架构收口。修复用户提的下载/AI/设置/UI 文案等问题。

---

## 修复 · Fixed（修复前 → 修复后）

### 下载管理器直接报错，几乎完全不能用
- **修复前**：单个任务卡片 build 抛错**整页染红**；下载通知 5 个文件 5 套实现（`ScaffoldMessenger.of(...).showSnackBar`）和 3 处页面内 `OgLNotifier.of` 通知风格不统一。
- **修复后**：单任务崩溃**只显示兜底卡片**（ErrorWidget.builder 隔离）；所有下载通知统一为 `OgLDownloadNotice.instance.show(context, surface, message, kind)` 单一入口，含 4 种 tone（queued/success/warning/info）+ 600ms 幂等去重 + 8s 时长。

### AI 对话返回的"正在处理..."没接上实际流
- **修复前**：AI 聊天用 `complete()` 一次性等全部回完才显示，没有打字机效果，也无法中途停止。
- **修复后**：改用 `completeStream()` 真实 SSE 流式（每帧 setState + 累积 buffer），用户可中途按**停止按钮**打断（cancels StreamSubscription，丢弃未完成 buffer 但保留已显示内容）。

### 设置页所有分组默认收起（反模式）
- **修复前**：首次进入设置页 5 个分组**全部收起**，用户要挨个点开看。
- **修复后**：**未持久化时全展开**（首次进入即看到所有设置），用户收起某组后才持久化偏好。

### 间距 / 边距满天飞裸数值（UI 混乱）
- **修复前**：8/12/16/24 这些间距值在 27 个文件里裸写（如 `SizedBox(height: 8)`），9 处 AI 页面 `EdgeInsets` 用裸数字。
- **修复后**：全栈统一用 `OgLSpace` token（xxs=4/sm=8/md=12/lg=16/xl=24/xxl=32 + vSm/vMd 等 SizedBox 工厂 + EdgeInsets 工厂），所有调用方零裸数值。

### 文档/CHANGELOG/Release 早已 9.0.0 但代码仍是老版本（9.1.0 才是 9.0.0 后真正第一版）
- 修复：本次发版同步代码现状到 9.1.0。
- 移除死代码 `lib/domain/sys/`（sys_access + sys_info + sys_platform_io 共 1080 行，零调用方）。
- 补 i18n 漏键 `copyFailed`（6 语言同步）。

## 变更 · Changed

- 版本推进 9.0 → 9.1。
- 间距系统：新增 `lib/surface/util/og_l_space.dart`。
- 删除 `lib/domain/sys/` 整个目录（连同其测试）。
- 网络层保持自研 2898 行（io_net_transport + net_bridge + net_dns + net_retry + range_download + ai_http_client + net_transport + net_mirror + net_self_test）：**完整覆盖重试/超时/DNS/Mirror/Range 分片/Transport 抽象**，是设计良好的契约层；换 dio / http / chopper 等成熟库**会破坏 web 平台隔离与 9 年测试积累的契约**。`url_launcher` 仅用于 surface 层开外链（`launchUrl`），是合适用法。
- DNS 层 659 行**不删**（设计完整：SystemDns / UdpDns / DohDns / Cache / Policy / Probe 分层）；sys_access 死代码删除 1080 行后，DNS 与 sys_info（也是死代码）**做保留评估**：sys_info 没人调用已确认，DnsService `n` 在 `net_bridge` / `io_net_transport` 真实使用——**保留 DNS**。
