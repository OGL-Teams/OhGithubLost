# OhGithubLost 10.1.0

本版本重做文件提交链路：保存后立即返回，提交在后台完成，结果经通知中心报告；同时修复一处提交状态误报，并落实前一轮审查发现的性能与界面一致性改进。

## 修复 · Fixed

- 保存文件后立即返回编辑器，提交在后台完成；此前用户需在页面等待全部提交步骤结束（网络较慢时可达数十秒）。
- 提交回执以服务端响应为准；此前回读校验失败会把"已经提交成功"误报为失败，导致重复提交。
- 待同步队列增加重试上限：反复失败的任务不再无限期挂起，超限后明确标记待处理。
- 提交失败的任务现会在运行期间自动重试；此前只在应用重启时补交。
- 移除账号时同时清理其草稿；此前被移除账号的草稿会永久留在设备上。

## 改进 · Improved

- 通知中心与首页徽标改用轻量计数，下载进行中不再整页重算。
- 图片预览与说明文档图片按屏幕尺寸解码，打开大图不再卡顿、内存占用大幅下降。
- 体积较大的接口响应与本地校验摘要移出界面线程，浏览大文件不再冻结。
- 下载管理页在多任务并行时保持流畅；目录过滤在输入时即时响应。
- 对话框、空状态与提示统一遵循全局界面规范；间距与图标尺寸全部使用设计令牌。
