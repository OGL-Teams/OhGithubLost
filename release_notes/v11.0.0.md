# v11.0.0

## 新增

- **发现页重做**：微博式上下滑动信息流。三个左右滑动子标签——
  - **动态**：star 仓库的 Release / Tag 发布提醒，卡片式纵向浏览（无 Release 时回退最新 tag）；
  - **推荐**：高星热门仓库纵向列表（匿名可用）；
  - **Issues**：聚合「我提出的」与「star 仓库新提出的」open issue，新的在上，支持 全部 / 我的 / Star 三档筛选。
- **仓库页右上角搜索**：一键进入代码搜索结果页，自动预填 `repo:<当前仓库> ` 限定词。
- **AppBar 滚动渐变融合**：随内容滚动从页面背景色连续插值到浮起色，取消阶跃色块与硬边。

## 修复

- 版本常量与 `pubspec.yaml` 同步至 `11.0.0`，「关于」页显示正确版本。

## 已知限制

- 文件提交 / 下载链路正在深度审查修复，本版可能仍受影响。
- Actions 日志 / 头像加速开关为预留项，未接入取数链路。
