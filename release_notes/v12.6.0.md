# v12.6.0 LTS

## 新增

- **下载重名裁决**：目标目录已有同名文件时自动落盘 `名称 (1).扩展名` 并顺延，绝不覆盖用户既有文件；同一条任务重试仍写原文件名。
- **下载进度可读**：任务行显示「已接收 / 总量 + 百分比 + 速率 + 线程数」，多连接任务如实标明并行度。
- **通知跳转加固**：入队通知条点「查看下载」一律走应用根导航，任何页面下都能正确打开下载管理；导航不可用时给出明确出路，不再静默。

## 修复

- 发现页三个标签的加载骨架与真实内容节奏对齐，加载完成不再闪跳。
- 推荐卡片摘要支持展开后收起；推荐加载失败时的重试按钮文案不再显示原文键名。
- 通知动作在根导航未就绪的极端时序下仍有明确降级提示。

## 改进

- 质量门禁体系全面收紧：门禁自身在异常工作目录下必须报错而不是静默通过（gate-of-gates）；分层审计覆盖 export 与内核文件头；动效/圆角令牌规则收紧；发布说明文案检查接入持续集成。
- 分层与桥接制度新增启动期守卫：层桥未注册齐全时拒绝启动，不再拖到运行期。
- 多语言补齐下载相关文案（简中 / 繁中 / 英 / 德 / 法 / 俄）。
- 仓库文档整理：九批审计总索引、文档分类地图、历史死链如实登记。

## 已知限制

- 动效节奏的逐项真机调优仍在进行；部分带自定义动作栏的页面沿用系统应用栏。
- 多连接下载的每分片限速未做，连接数上限沿用设置页既有档位。

## 产物

- Android（arm64-v8a / armeabi-v7a / x86_64 / universal APK / AAB）、Windows（x64 / arm64）、Linux（x64 / arm64），每份提供 zip 与 7z 双格式，共 23 件。
- macOS / iOS 自 v5.6.0 起不再提供。
