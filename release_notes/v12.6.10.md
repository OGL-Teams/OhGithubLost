# v12.6.10

正式版。本版为维护与审计收口版本，不改变用户可见的主要交互。
Formal release. This is a maintenance and audit-closure release; major
user-facing interactions remain unchanged.

## 新增 / Added

- 新增 Material 3 合规只读审计，按颜色、排版、形状、层级、组件、布局、导航、动效、无障碍、主题十类逐项评分，综合 90/100，无阻断项与警告项。
  Added a read-only Material 3 compliance audit covering ten categories—color,
  typography, shape, elevation, components, layout, navigation, motion,
  accessibility, and theming—scoring 90/100 with no critical issues or warnings.
- 设置、关于、用户页的单层平铺要求作为项目约束单列说明，不以通用设计惯例覆盖项目要求。
  Recorded the single-level flat layout of the Settings, About, and Profile pages
  as an explicit project constraint that prevails over generic design conventions.

## 改进 / Improved

- 文档索引补齐批次 9 至 12 与发布后专项报告；整理报告补充当前现状勘误。当前文档共 68 篇，相对链接死链为零。
  Completed the document index for audit batches 9–12 and post-release reviews;
  added a current-state erratum to the hygiene report. The documentation set
  contains 68 files with zero broken relative links.
- 版本一致性工具改为以脚本位置定位仓库，不再依赖当前目录；新增文档头部不得写死版本号的检查，并纳入元验证。
  Version consistency now resolves the repository from the script location rather
  than the working directory. A check prohibiting hard-coded version numbers in
  document headers was added and included in meta-verification.
- 元验证覆盖 11 支门禁，在错误工作目录下仍能证明各门禁具备检查能力，反向注入可拦下人为缺陷。
  Meta-verification now covers 11 gates, proving each retains its checking ability
  outside the repository root; negative injection is detected and rejected.

## 修复 / Fixed

- 修正一处等宽文本兜底字号，改用统一字号档位。
  Corrected one monospaced fallback size to use the shared type-size token.
- README 与工程规范头部不再写死版本号，避免文档数字静默腐烂。
  Removed hard-coded version numbers from the README and contributor-guide
  headers to prevent silent documentation drift.

## 说明 / Notes

- 本地十八道离线门禁全部通过，四层依赖零越级；类型检查与测试由持续集成裁决。
  All 18 local offline gates pass and the four-layer dependency graph has zero
  upward violations; type analysis and tests are adjudicated by CI.
- 前一版本的设置页平铺、字体加载、桌面输入与法律文本修复保持不变。
  The preceding release's flat settings layout, font loading, desktop input, and
  legal-text corrections remain unchanged.
