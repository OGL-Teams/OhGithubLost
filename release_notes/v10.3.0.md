# v10.3.0

## 新增

- **界面语言扩展至 6 种**：在简体中文与英文基础上新增 **繁體中文 / Deutsch / Français / Русский**，全部 1064 个界面键均为真实译文（zh_Hant/de/fr/ru 各 27 分片），经 B 站 Index-Translate 翻译管线生成并逐键校验（占位符完整、术语保留、六语言键集合一致）。设备语言自动匹配：繁体环境回落繁中。
- **下载令牌出设备警告弹窗（TOKEN-EXIT-01）**：凡下载请求会把 `Authorization` 令牌发给非 GitHub 主机时，先弹出**不可关闭**警告（遮罩 / 返回键 / 手势三重拦截），暗红背景，明确列出目标主机与风险；用户点「仍要下载」才继续，取消则不入队并如实提示。决策全部留痕可回溯。覆盖仓库文件下载、文件预览、Release 附件、Actions 产物四个入口。

## 修复

- **重定向凭证泄漏（NET-01 / NET-02）**：dart:io 自动重定向会在跨主机跳转时原样重发 `Authorization` 头。现在带凭证的请求改为手动跟随：同源跳转才带凭证，跨主机一律不跟随；Actions 日志下载在第一跳后剥离全部凭证头。
- **下载竞态（DATA-01）**：分片下载的失败 / 回退分支补回合校验——旧一轮迟到的失败回调不再覆盖新一轮状态，也不再与新轮并发写同一目标文件。
- **列表竞态（UI-01）**：`AsyncController.reset()` 后旧请求回写会把页面永久卡在加载态——加世代计数，过期回调一律丢弃。
- **通知丢失（UI-02）**：横幅通道缺失时通知被移出队列却不展示——现在放回队首补发。
- **页面退出崩溃（UI-03 / UI-05）**：复制链接 / 路径后立即退出页面会抛 deactivated-widget 异常——三处补 `mounted` 检查。
- **控制器泄漏（UI-04）**：自定义 DNS 对话框的 TextEditingController 从不释放——两条关闭路径均补 dispose。
- **重定向守卫编译错误（DBG-01）**：上一版重定向守卫引用未定义哨兵导致无法编译——已修复并用 mock 302 探针实证。

## 改进

- **CI 严格模式**：质量门全部审计步骤（分层 / i18n / 动效 / UI 细节度 / 性能 / 格式 / analyze / test）失败不再中断后续步骤，**全部跑完后一次性列出所有失败项并 fail**——修复者一次看到全部问题，不再被单项失败遮蔽。
- **构建严格模式**：构建矩阵删除 best_effort 宽松腿，任何平台构建失败即整体失败；CMake 预装失败也不再静默跳过。
