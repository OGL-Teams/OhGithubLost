# v13.0.0

本版新增仓库标签管理，并扩展设置页的可配置内容。
This release adds repository tag management and extends configurable options in Settings.

## 新增 / Added

- 仓库页新增「标签」子页，可分页浏览标签、查看目标提交，并支持创建与删除。
  A new Tags tab in the repository page supports paginated browsing, target-commit display, creation and deletion.
- 标签创建基于 Git refs 生成轻量标签，不生成 Release；删除为破坏性操作，界面默认二次确认。
  Tag creation uses Git refs to produce lightweight tags without creating a Release; deletion is destructive and confirmed by default.
- 设置页新增标签排序、每页数量与删除前确认三项偏好，均为客户端设置并持久化保存。
  Settings gains three persisted client-side preferences: tag order, page size and deletion confirmation.

## 接口 / API

- 逻辑层新增标签列表、单标签读取、创建与删除接口；请求方法、路径与请求体由离线回归覆盖。
  The domain layer adds list, read, create and delete tag endpoints; methods, paths and bodies are covered by offline regression tests.
- 页面仍经既有领域桥访问接口，未新增跨层依赖；四层依赖方向保持单向。
  Pages continue to use the existing domain bridge; no new cross-layer dependency is introduced and the four-layer graph remains unidirectional.

## 文档与检查 / Documentation and Gates

- 新增标签功能计划，明确目标层级、七个实施阶段、设置契约与 API 契约。
  A feature plan defines target layers, seven stages, the Settings contract and the API contract.
- 文档体系统一契约落地：正式内容中英逐条对照，历史报告不追溯改写。
  The unified documentation convention is in effect: bilingual formal content, with historical reports left unchanged.
- 六语言文案、离线回归、十一支门禁与元验证全部通过；类型检查与测试由持续集成裁决通过。
  Six-language copy, offline regression, eleven gates and meta-verification pass; type analysis and tests pass in CI.

## 兼容性 / Compatibility

- 旧配置缺少新增设置项时使用保守默认值，不改变既有体验。
  Existing configurations without the new keys use conservative defaults; prior behavior is preserved.
- v12.6.x 的设置页平铺、字体加载、桌面输入与声明文本修复保持不变。
  The v12.6.x fixes for flat Settings, font loading, desktop input and legal texts remain intact.
