# v11.3.0

## 新增

- **文件提交端到端回归守卫**：新增测试锁定「编辑既有文件提交成功且请求体完整发出」「远端冲突不被误判为文件不存在」，防止提交链路问题复发。
- **权限网关版本自适应**：存储权限请求按结果自动降级（先请求「所有文件访问」，失败回退传统存储权限，再以真实写入探针确认）；Android 5.1（API 22）起全版本可用。

## 改进

- **凭证保护接线补完**：跨主机跳转的敏感头集合扩展（authorization / cookie / api-key 等六种）；请求降级为 GET 时剔除与请求体绑定的头部。
- **设置页文案精简**；法律文本以正式许可原文为准。

## 修复

- **文件无法提交（重大）**：此前保存文件会无响应或失败，根因有三处——网络守卫把带凭证请求的请求体丢弃；重定向把保存请求降级为空请求；本地缓存引擎在锁内自我等待造成死锁。三处均已修复并有回归测试锁定。
- **保存冲突处理**：远端返回不完整时不再误判为「文件不存在」而覆盖他人内容；无法确认远端状态时明确失败并保留本地内容。
- **草稿保护**：从草稿箱打开草稿后直接退出，草稿不再被自动删除。

## 变更

- 组织级 GitHub OAuth App 的 Client ID 可经构建注入，登录页在未配置时自动隐藏授权入口。
