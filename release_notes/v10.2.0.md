# OhGithubLost 10.2.0

本版本修复一处导致仓库列表与搜索结果全部为空的数据解析缺陷，新增 GitHub 账号授权登录，并简化首次启动引导。

## 修复 · Fixed

- 仓库列表与搜索结果此前可能全部为空：较大返回内容的解析结果被误当成异步值，导致数据取到了却显示不出来。现恢复正常解析。
- 网页版写入大文件时的校验计算会失败，现改为在浏览器内直接计算。
- 仓库页切换标签后目录路径不再被重置；打开文件后返回仍停留在原目录。
- 仓库页标签数量随权限加载变化导致的跳回第一个标签问题已修复。
- 删除仓库按钮按管理员权限显示；无权限时说明原因，不再点了才报错。
- 议题列表的关闭按钮仅对有权限的账号显示。
- 加速通道说明、法律声明等处的格式符号不再原样显示。

## 新增 · Added

- 支持使用 GitHub 账号授权登录：在浏览器输入一次性代码即可完成，无需手动创建访问令牌。未配置该登录方式的版本仍可使用令牌登录。

## 改进 · Improved

- 首次启动引导由六步精简为三步；引导、权限与登录相关文案整体精简，去掉了操作步骤与内部机制的解释。
- 界面强调色与选中状态更明确：导航与列表选中项使用主题色，卡片与页面区分更清楚。

## 变更 · Changed

- 登录流程的令牌验证、账号切换与本地校验合并为一条共用链路，令牌登录与授权登录行为一致。
