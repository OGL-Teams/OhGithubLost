# OhGithubLost 10.0.0

本版本移除 AI 助手及相关数据，界面收敛为简体中文与 English；集中修复文件编辑与提交中的数据安全问题，并统一文案、确认操作和界面反馈。

## 移除 · Removed

- 移除 AI 对话、AI 设置、模型配置、工具调用及全部入口。
- 移除相关网络请求、后台审计任务与专用资源。
- 升级后清理本机遗留的 AI 密钥、会话与操作记录，不影响 GitHub 账号和仓库数据。
- 界面仅保留简体中文与 English，移除其余语言。

## 修复 · Fixed

- 从文件列表进入编辑器前重新读取完整文件，避免把目录摘要或空内容写入原文件。
- 非 UTF-8 文件不再进入可保存的文本编辑流程，防止编码转换破坏原始字节。
- 恢复草稿时保留其原始版本基线；远端已变化时仍会进入冲突检查。
- 草稿保存与删除按文件顺序执行，防止旧写入覆盖新内容或复活已提交内容。
- 文件名包含 `#`、`?` 等字符时，读取、保存与删除使用正确路径。
- 删除文件时校验用户确认的版本，避免误删之后出现的新版本。

## 改进 · Improved

- 全面校正中英文案，修复英文设置页的错位内容，统一常用操作与错误提示。
- 普通错误提示不再直接展示异常类型、堆栈或内部路径。
- 放弃修改确认、对话框动画、提示方式和间距统一遵循全局界面规范。
- 保存成功、远端冲突与本地草稿清理的结果分别呈现，避免误报提交失败。
