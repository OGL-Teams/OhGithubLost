# v13.3.0（rc 候选发布）

本版把上一版重写的界面文案补齐到全部 30 种语言，并新增语义色对比度门禁。这是 v14 正式版前的候选发布版本。
This release brings the rewritten interface copy to all 30 languages and adds a semantic-color contrast gate. It is the release candidate before the v14 stable release.

## 翻译 / Translation

- 上一版修正的 22 个文案键（错误消息写明后果与可逆性、空态给出下一步、按钮动词式）现补齐到其余 24 种语言，全部按源文快照逐条精翻，占位符逐字节保留。
  The 22 corrected copy keys now ship in all 24 remaining languages, translated against source snapshots with byte-exact placeholders.
- 增量翻译流水线复用源值快照机制：源文中途改动不会造成前后批次译文不一致。
  The incremental pipeline reuses source snapshots, so mid-flight source edits cannot cause inconsistent batches.

## 检查 / Verification

- 新增**语义色对比度门禁**（第 12 支门禁）：对成功 / 警告 / 信息语义色按 WCAG 2.1 计算，正文级 ≥ 4.5:1、图形级 ≥ 3.0:1，当前全部通过，调色回归会被拦截。
  A new semantic-color contrast gate (the twelfth gate) computes WCAG 2.1 ratios for success / warning / info colors — 4.5:1 for text, 3.0:1 for graphics; all pass today and regressions will be blocked.
- 布局断点补充决策说明：自研三档断点与 Material 3 规范断点对齐，官方窗口类别接口仅 Android 可用，全平台统一口径保持零依赖。
  Layout breakpoints gained a decision note: the in-house three-tier scale matches Material 3 canonical breakpoints, chosen because the official window-size-class API is Android-only and the project stays dependency-free across all platforms.
- 十二支门禁与元验证通过；类型检查与单元测试由持续集成裁决。
  Twelve gates and meta-verification pass; type analysis and unit tests are judged by continuous integration.

## 候选发布说明 / Release Candidate Note

- 本版本为 rc 候选发布：功能冻结，若验证无回归将作为 v14 正式版的基础。
  This is a release candidate: features are frozen; pending verification it becomes the base of the v14 stable release.
