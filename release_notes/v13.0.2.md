# v13.0.2

本版将界面语言从 6 种扩展至 30 种。新增 24 种语言由语言能力逐分片精译，并对既有语言全量润色，清除长期残留的英文占位。
This release expands the interface from 6 to 30 languages. Twenty-four new languages were translated shard by shard, and existing languages were polished to clear long-standing English placeholders.

## 新增 / Added

- 新增 24 种界面语言：日语、韩语、西班牙语、葡萄牙语、意大利语、荷兰语、波兰语、土耳其语、阿拉伯语、印地语、泰语、越南语、印尼语、马来语、乌克兰语、捷克语、瑞典语、丹麦语、芬兰语、挪威语、匈牙利语、罗马尼亚语、希伯来语、希腊语。
  Twenty-four interface languages added: Japanese, Korean, Spanish, Portuguese, Italian, Dutch, Polish, Turkish, Arabic, Hindi, Thai, Vietnamese, Indonesian, Malay, Ukrainian, Czech, Swedish, Danish, Finnish, Norwegian, Hungarian, Romanian, Hebrew and Greek.
- 每种新语言均覆盖全部 28 个页面分片、1272 个键；法律与声明正文逐句翻译，非机器翻译、非英文占位。
  Each new language covers all 28 page shards and 1272 keys; legal and notice texts are translated sentence by sentence, with no machine translation or English placeholders.
- 新增逐分片译文校验工具，强制键集合、键顺序与占位符与简体中文一致。
  A shard-level translation checker enforces key sets, key order and placeholders against Simplified Chinese.

## 润色 / Polished

- 繁体中文、德语、法语、俄语全量润色：清除 issue 页面等处的整句英文残留，统一术语，修正占位符与键顺序。
  Traditional Chinese, German, French and Russian polished: whole-sentence English residue in the issue page and elsewhere cleared, terminology unified, placeholders and key order corrected.
- 英文保留为基线语言。
  English remains the baseline language.

## 检查 / Verification

- 30 种语言全部通过逐分片校验；键集合、键顺序与占位符零差异。
  All 30 languages pass shard-level verification with zero differences in key set, key order and placeholders.
- 十一支门禁与元验证通过；类型检查与单元测试由持续集成裁决。
  Eleven gates and meta-verification pass; type analysis and unit tests are judged by continuous integration.

## 兼容性 / Compatibility

- 首次启动按设备语言自动选择界面语言，未识别语言仍回落简体中文。
  First launch selects the interface language from the device locale; unrecognized locales still fall back to Simplified Chinese.
- 既有功能与产物行为不变。
  Existing features and artifact behavior are unchanged.
