# v7.4.2 · Web 双产物发布（dart2wasm + dart2js 入口分流）

## 一、本次定位

7.4.1 已经把"v7.4.0 部署后还存在的问题"补完，本版在 Web 端做**冷启动优化**与**老浏览器兼容兜底**。

目标：
- 现代浏览器（Chrome 89+ / Firefox 89+ / Safari 16.4+）→ **dart2wasm** 主载，首屏体积从 5.2MB 降到 < 1MB
- 老浏览器（Safari 15 / Chrome < 89 / IE）→ **dart2js** 兜底，行为不变
- 同一版本发布**两份**产物，入口页嗅探分流

## 二、修改总览（4 个文件）

### 1. `.github/workflows/web.yml`（CI 双构建）
- **新增**第二个构建 step（dart2js 兜底），保留原有 dart2wasm 主载
- **新增**"验证双产物"step：强校验两个产物目录都有 index.html，且 wasm 主载含 `main.dart.wasm`、js 兜底含 `main.dart.js`
- **双发布**：先 `app/wasm/<版本>/`、后 `app/js/<版本>/`（wasm 优先）
- **双 artifact**：`ogl-web-wasm` 与 `ogl-web-js` 各 14 天保留
- **策略**：`mv build/web build/web-wasm` + `mv build/web build/web-js`（避开 `--output` 目录已存在检查）
- **防 cache 错位**：`--no-tree-shake-icons` 让两轮构建幂等
- **timeout 40 → 50 分钟**（双构建预估 +15 分钟）

### 2. `tool/web_publish.py`（支持 subdir + 双桶管理）
- **新增** `--subdir` 参数：`wasm` / `js` / 默认空串
- **新增** `app_path_with_subdir()`：默认空 → `app/<v>/`，传 wasm → `app/wasm/<v>/`
- **`versions.json` schema**：每条 entry 增加 `variant` 字段（`""` / `"wasm"` / `"js"`），按 `(dir, variant)` 复合键去重
- **`_read_manifest()` / `_dedupe()`**：容错读取 + 智能去重；旧 entry 无 `variant` 字段用 `.get('variant', '')` 兜底
- **覆盖 bug 修复**：`--subdir js` **不**重写 `versions.json` 与 `app/index.html`（wasm 桶作为权威写者）
- **入口页**：每次发布都重写 `app/index.html`（wasm 嗅探分流模板）；`__CURRENT__` 给 favicon、`__OGL_VERSION__` 给底部 JS 拼路径

### 3. 入口页 `app/index.html`（wasm 嗅探分流）
- **双层 Wasm 嗅探**（`<head>` 顶部同步脚本，iframe 拿到 src 前必执行完）：
  1. 基础 `WebAssembly.validate(字节码)`（Chrome 57+ / Firefox 52+）
  2. **Wasm GC struct/array ref** 字节序列（dart2wasm 必需；Chrome 89+ / Firefox 79+ / Safari 16.4+）
- **iframe 引导**：初始 `src="about:blank"`，底部同步脚本按 `__OGL_VARIANT__` 拼 `./wasm/<dir>/` 或 `./js/<dir>/`
- **兜底**：嗅探失败 → `'js'`；iframe onload 淡出 loader；20s 超时兜底
- **iOS Safari 提示**：保留"添加到主屏幕"说明，新增 `<noscript>` 兜底

### 4. `web/_headers`（Netlify CDN 缓存策略）
- `/assets/*`、`/canvaskit/*`、`*.wasm`、`*.js`、`*.png` 全部 `max-age=31536000, immutable`
- 根路径 `must-revalidate`
- `flutter_service_worker.js` 也 `must-revalidate`
- 二次访问走 CDN 304 命中

## 六、浏览器兼容矩阵

| 浏览器 | 最低版本 | 年份 | 走哪条路 |
|---|---|---|---|
| Chrome / Edge / Opera / Vivaldi / Brave / Arc | 89+ | 2021 | wasm 主载 |
| Firefox / LibreWolf / Waterfox | 89+ | 2021 | wasm 主载 |
| Safari / iOS Safari / WebKit | 16.4+ | 2023-03 | wasm 主载 |
| 旧 Chrome (57-88) | 2017-2021 | | js 兜底 |
| 旧 Firefox (52-88) | 2017-2021 | | js 兜底 |
| 旧 Safari (11-16.3) | 2017-2023 | | js 兜底 |

**也就是说**：iOS 16.4 起（2023-03）所有苹果设备、所有 2021 年后的桌面浏览器都吃 wasm 高性能路径；更老的浏览器自动降级到 dart2js。
