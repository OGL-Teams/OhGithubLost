# v7.4.2 · Web 双产物（dart2wasm 主载 + dart2js 兜底）· 冷启动优化

## 一、本版解决的两个真问题

### 1. 国内冷启动慢 —— CanvasKit 走 Google CDN
Flutter 默认让 `flutter_bootstrap.js` 从
`https://www.gstatic.com/flutter-canvaskit/<hash>/` 拉 CanvasKit
（`canvaskit.js` + `~1.5MB` `canvaskit.wasm`）。**该域名在国内基本不可达**，
首屏卡在等待超时——与主包大小无关。

**修法**：构建加 `--no-web-resources-cdn` → CanvasKit 打进产物
`canvaskit/`，bootstrap 改用**同源相对路径**，从自己的域名 / CDN 加载。
配合 `web/_headers` 的一年 `immutable` 缓存，二次访问零等待。

### 2. dart2wasm 编译被 transitive dep 卡死
失败链：
```
re_editor → isolate_manager ^4.1.5+1 → isolate_contactor ^4.0.0
                                      → dart:html   ❌ dart2wasm 不支持
```
`isolate_contactor 4.2.0` 虽已迁到 `package:web`，但它约束 `web: ^0.5.1`
（0.x 的 caret 锁死 minor → `<0.6.0`），与本项目 `http 1.x` 需要的
`web: ^1.0.0` **直接冲突** → pub 只能退回 4.1.0。

**修法**：`dependency_overrides: isolate_manager: ^6.3.2`
- 6.x **彻底删除** `isolate_contactor`，自身直接用 `package:web`（`web: ^1.0.0`，与 http 相容）
- 对外 API 与 re_editor 用法一致：`IsolateManager.create(fn, concurrent: n)` /
  `.compute(p, callback:)` / `.stop()`
- lib/ 内**零** `dart:html`
- 只改版本求解，不动任何第三方源码

## 二、产物结构

```
app/
├── index.html          ← 入口：双层 wasm 嗅探 → iframe 分流
├── versions.json       ← [{version, dir, variant:'wasm'|'js'}]
├── wasm/742/           ← dart2wasm 主载（<1MB）
├── js/742/             ← dart2js 兜底（~5MB）
└── 741/ 722/ …         ← 历史版本保留
```

## 三、入口页分流

`app/index.html` 顶部**同步**嗅探（iframe 取 src 前必执行完）：
1. 基础 `WebAssembly.validate(...)`
2. **Wasm GC struct/array ref** 字节序列（dart2wasm 必需）

→ `window.__OGL_VARIANT__ = 'wasm' | 'js'` → iframe 指向
`./wasm/<版本数字>/` 或 `./js/<版本数字>/`。
