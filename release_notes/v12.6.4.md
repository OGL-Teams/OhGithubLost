# v12.6.4

## 架构

- **层级倒置全清**：`GhClient` 与 `GhApi` 不再直接依赖底座实现，改为依赖启动层契约；`CacheRemote` 从底座上提到契约层，由底座转发导出。装配根注入实现，逻辑层不再认识底座具体类型。
- **新增门面类型面门禁**：唯一类型门面不得导出服务/实现类，层桥不得新增暴露底座实现的字段；基线锁定现有字段，反向注入可拦。门禁已接入持续集成与「门禁之门禁」自检。
- **平台层规则修复**：原先「平台层只许依赖内核」的规则因被跳过而从未执行，现纳入扫描并生效。

## 下载

- 撤销「移除」真正把任务放回列表，不再点到空记录；移除留下的重名豁免被正确消费。
- 分片回退单连接增加回合守卫，旧回合不再覆盖新回合的路径或重复入队。
- 单连接下载失败、入队失败统一投递通知，离开下载页也看得见。
- 完整性校验失败时按「坏文件已删除 / 未能删除」分别如实提示，不再无条件宣称已删除。
- Gist 下载改用统一通知条，自带「查看下载」入口；极端时序下的降级不再依赖已退出的页面。

## 域名解析与网络

- 自定义服务器地址为空或非法时明确拒绝并留痕，不再悄悄沿用旧服务器；地址入库与候选生成两处都做协议/白名单校验。
- 同域名并发解析合并为一次；域名解析回退到系统的实际通道在界面摘要中可见。
- 承接前版：私网、回环与云元数据地址在解析结果和自定义服务器两侧都被拒绝。

## 已校准与已知限制

- 私有仓库的 README 图片一直走带令牌的内容接口取字节，报告里「必然 404」的结论不成立。
- 仓库文件没有可靠的 sha256 摘要源；编造摘要比不校验更坏，因此该类别保持「未校验」而非假校验。
- 能力体系消费侧、依赖注入的层隔离、可变状态对象转只读视图、发布签名覆盖与工作流版本固定，属需逐小步验证的高风险专项，仍按路线图跟踪。
- 部分动画节奏需要真机采集后定档，未做静态硬编码。
