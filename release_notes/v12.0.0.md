# v12.0.0 LTS

## 新增

- **发现页重做**：动态（关注仓库的发布通知与类型标识）、推荐（按语言分类、长按操作菜单）、问题聚合（本人与关注仓库的新问题，按时间与来源筛选），全部改为上下滑动的信息流；加载期间显示骨架占位。
- **仓库设置**：可编辑描述、主页地址与主题标签；可切换公开或私有（含影响面确认）；支持将仓库转移至其他账号（危险操作二次确认）。
- **议题功能补齐**：可编辑标题与正文、管理标签与指派人、锁定或解锁讨论、编辑或删除自己的评论；相关操作仅对有权限者显示。
- **工作流日志增强**：支持日志内查找与高亮跳转、按作业分组折叠、失败作业置顶、将日志保存到本地、重新运行失败作业与取消运行；失败均如实提示。
- **外观字体管理**：界面字体可选系统默认、内置等宽字体 Ubuntu Mono、思源宋体（按需下载），并支持添加私有字体（本地文件或链接）；删除当前使用中的字体自动回落系统默认。
- **Android 5.1 起全版本支持**：安装包最低系统要求固定；存储权限在各系统版本间自动回退，最终以真实写入确认。

## 改进

- 设置页层级重设，界面分组的字体选择与管理入口以缩进子项归属呈现。
- Windows 与 Linux 的证书校验说明更明确：走系统证书栈，不旁路校验。
- 结构契约门禁接入持续集成，可检查导出指向、文件头层级、平台门面与文档引用。
- 说明文档逐项同步至实际行为（网络连接、架构层级、一致性契约、组织授权配置）。

## 修复

- **文件提交与保存**：修复请求体在带凭证时被丢弃、重定向错误降级、缓存锁自锁、冲突误判覆盖、不完整回执等导致保存无响应或失败的问题，并补端到端回归测试。
- **下载可靠性**：分片规划保证每片大小、逐字节区间校验、单一分片失败不影响其余收尾；探测失败留痕。
- **网络与解析**：请求超时按各请求设定生效；重试遵守服务端等待要求；更换自定义解析服务立即生效；拒绝错误域名、私网与内网解析器应答。
- **缓存与草稿**：冲突重试不再盲写覆盖；本地读取失败不再伪装为「文件不存在」；定期淘汰旧缓存；从草稿箱打开草稿不再被静默删除。
- 代码与日志的等宽字体在各桌面系统观感一致。

## 已知限制

- 网页版本仍不支持账号授权登录，仅可使用个人访问令牌；浏览器下载与通知由浏览器自身权限决定。
- 用户自备的加速通道不属于本应用提供的服务，其兼容性、可见性与数据处理由该通道决定，启用前需知情接受。

## 说明

本版本作为长期支持基线：前述功能与修复均已通过持续集成验证，后续维护以修复为主，不再向此基线追加高风险架构变更。
