# v15.0.0

本版是 UX 稳定性大版本：依据 15 席交叉审计（约 320 条问题、去重后 61 条确证）分四批完成修复，直指「空、漂浮感、没有作为工具的稳定感」三项主诉。
This is the UX stability release: fifteen cross-audits produced roughly 320 findings consolidated into 61 confirmed issues, fixed in four batches targeting the three complaints — emptiness, a floating feel, and the lack of a tool's sense of stability.

## 第一批 · 主题层根治 / Batch 1 — Theme-level fixes

- 新增 outlineVariantStrong 语义色（WCAG ≥3:1）：分割线、卡片描边、Chip、分段控件、弹层把手与输入框空闲态边界统一取用，消除「边界消失」。
  A new outlineVariantStrong token (WCAG ≥3:1) is used by dividers, card strokes, chips, segmented controls, sheet handles and idle input borders, ending "vanishing edges".
- 卡片底色升级并补投影，弹层按层级升档；暗色 SnackBar 动作色可读；AppBar 滚动边界、导航轨主题与禁用态统一。
  Card surfaces gain contrast and shadows; overlays step up by hierarchy; dark-mode SnackBar actions become legible; app-bar scroll elevation, navigation rail theming and disabled states are unified.

## 第二批 · 骨架与状态 / Batch 2 — Skeletons and states

- 加载态改为二段式骨架屏，替代纯空白屏加裸转圈；空态增加下一步操作按钮，错误态可重试。
  Loading states use structured skeletons instead of a blank screen with a bare spinner; empty states gain next-step actions; errors offer retry.
- 300ms 防抖与最小显示时长避免加载态一闪而过；法律与引导页不再把加载失败误显示为「没有内容」。
  Debounce and a minimum display duration stop loading flashes; legal and onboarding pages no longer render load failures as "no content".

## 第三批 · 外壳与转场 / Batch 3 — Shell and transitions

- 宽屏限宽只作用于内容，AppBar 全宽；切页透明度与位移收敛；滚动融合不再是死代码；启动底色跟随主题、失败页可滚动。
  Wide-screen width limits apply to content only with a full-bleed app bar; tab-switch opacity and motion are tightened; scroll fusion is no longer dead code; the splash follows the theme and the failure page scrolls.
- 页面转场取消整页缩放、补对向退场与返回链接力；统一复制/刷新/删除等语义图标。
  Page transitions drop full-page scaling and add reverse exit with back-gesture continuity; copy/refresh/delete icons use one semantic layer.

## 第四批 · 反馈闭环 / Batch 4 — Feedback closure

- 危险确认统一 error 色 helper；SnackBar 三语气以底色、图标与前景色区分；写操作补忙碌态与防重入，成功有确认、失败可重试。
  Destructive confirmations use one error-colored helper; SnackBar tones differ by background, icon and foreground; write operations gain busy states, re-entry guards, success confirmation and retry.
- 关键可点击行补读屏语义，图标按钮命中区达到 48dp。
  Key tappable rows gain screen-reader semantics; icon button hit areas reach 48dp.

## 检查 / Verification

- 12 支门禁、元验证、单元测试与全平台构建由持续集成裁决通过。
  Twelve gates, meta-verification, unit tests and all-platform builds pass in continuous integration.
