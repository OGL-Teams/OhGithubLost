# v12.6.8

## 桌面与输入

- 新增全局快捷键：Ctrl+S 保存、Ctrl+F 查找、Ctrl+R 刷新、Esc 关闭；代码编辑器接入保存、查找与关闭。快捷键仅在桌面类平台启用，平台判定统一经平台门面。
- 发现页仓库卡片与 Release 附件增加可见的「更多操作」按钮；长按入口保留，但不再作为桌面端唯一可达方式。
- 用户提示在消息容器已卸载时不再静默丢弃，改为写入应用日志留痕。

## 设置与声明

- 设置页改为单层平铺：根页仅列分类入口，子页由标题栏标明分类，条目直接呈现；不再使用圆角卡片气泡与可折叠分组头，也不再保留折叠状态。
- 法律与声明文本六语言重写为规范书面语，补齐适用法律与争议解决、不可抗力与责任限制、第三方链接与内容、知识产权、账号与令牌责任、终止使用、未成年人、变更生效等条款。
- 关于页的致谢、协议说明与贡献者名单用真实内容；相关文案去除夹生术语，引号与措辞统一。NOTICE 增加商标条款并与依赖许可清单对齐。

## 审查

- 全量检查四层依赖：无向上越级调用，跨层引用全部集中在层桥。
- 新增 UI 全面审查报告，覆盖控件语义、动效档位、操作逻辑、屏幕尺寸与输入方式；本版修复其中桌面输入与操作逻辑的高优先级项。
- 回归锁禁止设置页卡片气泡与折叠分组回退，并要求法律正文关键条款保持在位。

## 说明

- 桌面刷新替代入口、一级列表宽度约束、编辑器右键菜单、代码字号令牌与表单键盘提交，仍需按报告分批推进或真机验证。
- 前版的层级桥接、下载、域名解析与质量门禁修复保持不变。

## 产物

- Android（arm64-v8a / armeabi-v7a / x86_64 / universal APK / AAB）、Windows（x64 / arm64）、Linux（x64 / arm64），每份提供 zip 与 7z 双格式，共 23 件。
- macOS / iOS 自 v5.6.0 起不再提供。
