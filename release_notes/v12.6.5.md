# v12.6.5

## 架构

- **能力体系落地**：模块声明的能力标识在启动期校验唯一性与格式，并进入依赖图与诊断报告；此前它们只是装饰性字符串，没有任何消费侧。
- **依赖注入层隔离**：新增按层注册与解析的命名空间，跨层不能意外取到别层的服务；既有全局注册方式保持兼容，新代码有正确的隔离路径。
- **可变实现类型面锁定**：层桥直接持有的实现类字段建立基线，新增同类字段会被门禁拦下；全量改为只读视图仍按路线图推进。
- **平台层文件头规范**落地，并纳入结构契约审计。

## 域名解析

- DoH 现在支持 IPv6 记录、别名链跟随与 TTL 判定，不再只认 IPv4 地址记录。
- 应答缺少归属域名时直接拒绝，堵住此前可绕过归属校验的窗口；DoH 端点在使用前二次校验，查询同时覆盖 IPv4 与 IPv6。
- 同域并发解析合并、回退通道可见等前版修复保持不变。

## 发布与质量门禁

- 引导清单的源码指纹新增覆盖平台门面与组合根，签名范围不再留缺口。
- 新增工作流第三方动作版本守卫：禁止浮动分支、版本必须与已审基线一致。
- 新增动效档位覆盖守卫：裸动效的时长必须走档位表，档位消费点数量有下限；门禁总数增至十支，并全部纳入「门禁之门禁」自检。

## 已校准与已知限制

- 网络自检报告原本就随连接异常附带到界面，并非完全不可见。
- 自签证书走构建密钥与仓库 Secret，仓库内无明文签名密码。
- 逐帧动画节奏与四页入场动画仍待真机采集后定档；静态硬塞数值在此前批次已被证明会造成回归。
- Web 分支实编、库同名覆盖行为、分片取消后临时文件撞车，属需真机或独立环境验证的推测项。
- 第三方下载库内部的跨主机跳转仍是已知暴露面；签名地址失败时已强制直连并给出警告。

## 产物

- Android（arm64-v8a / armeabi-v7a / x86_64 / universal APK / AAB）、Windows（x64 / arm64）、Linux（x64 / arm64），每份提供 zip 与 7z 双格式，共 23 件。
- macOS / iOS 自 v5.6.0 起不再提供。
