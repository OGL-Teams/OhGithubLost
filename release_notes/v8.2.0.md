## 新增 · Added

### AI 助手
- 聊天：会话历史、多轮对话、真实 SSE 流式（原生端增量、Web 端缓冲解析）；
  回复以**纯文本**渲染（不使用 markdown）。
- 三协议适配：OpenAI 兼容 / Claude Messages / Gemini GenerateContent，含**工具调用**。
- 工具集（只读）：`list_files` / `read_file`，复用 `GhApi`。
- 设置：服务商 / 协议 / 模型 / 端点 / 密钥（密钥只进 `DiskVault`，端点为纯 HTTPS）。
- **AI 操作永久落盘**：每次工具执行写一条审计（`DiskKv`，每账号 200 条上限）。
- 日志 / 通知接入：每次收发写 `OgLAppLog`（自动进入通知中心）。

### 主页导航（bar 重构）
- 底栏 / 导航轨由「首页 · 搜索 · 我的 · 设置」改为「**仓库 · 搜索 · AI · 个人**」。
- 「设置」移入「个人」页内（外观 / 网络 / AI / 关于）。

### 设置页两级层级
- 第一层**进入式**：设置主页为分类入口（外观 / 代码与文件 / 存储与网络 / AI / 关于 / 日志），点开进入分区页。
- 第二层**折叠式**：分区页内为可折叠分组（折叠状态共享、退出记忆）。

### 下载中心直达
- 下载入队后弹 SnackBar，带「查看下载」动作**直达下载中心**（此前只有一句提示，看不到进度）。

## 修复 · Fixed（修复前 → 修复后）

### AI 配置 HTTP 端点崩溃
- **修复前**：在 AI 设置中填写以 `http://` 开头的端点，应用崩溃并弹出未捕获异常。
- **修复后**：HTTP 与 HTTPS 端点均可填写并保存；应用不再因协议差异闪退，UI 仅以提示条告知混合风险。

### 下载文件不进 ogl 目录
- **修复前**：开启「使用 ogl 目录」授权后，已经完成的下载仍然出现在系统「下载」目录；
  在 ogl 目录内看不到任何文件，给用户造成「授权无效」的感觉。
- **修复后**：授权后完成的下载**立即可见**于 ogl 目录；授权前的下载保持原位置不变。

### 同一附件第二次下载失败
- **修复前**：在附件列表上点击「重新下载」没有任何反应，进度条不动，已存在的临时文件未被复用。
- **修复后**：再次下载直接进入新一轮传输，进度条从头走起，旧文件被自动清理。

### 悬浮按钮遮内容
- **修复前**：主页 FAB 一旦露出，最后一行内容被压住，需要主动下拉才能看全。
- **修复后**：FAB 下滑时**自动收边**——只露出边缘 1/4，点击即弹回，上滑自动展开。

### 设置页点进去先见折叠组
- **修复前**：进入任意设置分区页，先看到一组折叠状态的控制项，要么空白要么折叠，需逐个展开。
- **修复后**：进入分区页即**直接看到所有项**，无需手动展开。

### 两级页面留白差一倍
- **修复前**：从一级（设置主页）push 到二级（分区页）后，卡片视觉上变宽一倍左右，与主页排版脱节。
- **修复后**：两层页面采用**统一的边距与行间距**，视觉连贯一致。

### 剪贴板在外链打开失败时不工作
- **修复前**：点击「在浏览器中打开」失败时，原本应复制到剪贴板的链接没有复制，用户得不到回退。
- **修复后**：外链打开失败时，**自动复制完整链接到剪贴板**，并以通知告知。

### 通知横幅不收回
- **修复前**：底部通知横幅出现后瞬间消失，用户来不及看清内容。
- **修复后**：通知横幅**停留 8 秒**后自动收回，期间可点击动作立即触达详情。

## 平台

- 原生端：AI 传输走 `dart:io`（真 SSE 流式）；密钥走 Keystore / DPAPI / libsecret。
- Web 端：AI 传输走 `package:http`（SSE 缓冲解析）；密钥存 localStorage（浏览器固有限制，已在界面提示）。
