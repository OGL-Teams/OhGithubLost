# v13.0.1

本版落地多语言增量翻译基础设施，并完成 24 种语言的标签界面精翻；同时修复持续集成配置中的两处问题。
This release establishes incremental translation infrastructure and completes refined translations of the tag interface in 24 languages; it also fixes two continuous-integration configuration issues.

## 新增 / Added

- 增量翻译基础设施：任务书、差值提取与校验工具，并记录源文快照，避免源文中途改动造成前后批次译文不一致。
  Incremental translation infrastructure: a task brief, delta extraction and verification tools, and source snapshots to keep batches consistent when source text changes mid-flight.
- 校验增加跨语言一致性检查，可发现同一键在不同语言间词性或句式不统一的问题。
  Verification adds a cross-language consistency check to catch part-of-speech or sentence-pattern drift for a key across languages.

## 翻译 / Translation

- 24 种语言完成标签界面精翻与句式、术语对齐；精翻产出暂存于独立工作区，不影响主干既有语言。
  Twenty-four languages receive refined tag-interface translations with aligned sentence patterns and terminology; output is staged separately and leaves production languages untouched.
- 「新建标签」按钮文案在中文、繁体中文与英文中统一为名词式，与对话框标题的动词式区分。
  The "New tag" button label is standardized to a noun form in Simplified Chinese, Traditional Chinese and English, distinct from the verb form used in the dialog title.

## 检查与修复 / Verification and Fixes

- 清理翻译工作流配置中的文本污染，登记官方 setup-python 动作版本；质量门与全平台构建均通过。
  Removed stray text from the translation workflow configuration and registered the official setup-python action version; quality gates and all-platform builds pass.
- 十一支门禁与元验证通过；类型检查与单元测试由持续集成裁决通过。
  Eleven gates and meta-verification pass; type analysis and unit tests pass in CI.

## 兼容性 / Compatibility

- 仅涉及翻译基础设施、文案与持续集成配置，不改变既有功能与产物行为。
  Changes are limited to translation infrastructure, copy and CI configuration; existing features and artifact behavior are unchanged.
