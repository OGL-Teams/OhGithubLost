# v12.4.0

## 修复

- **发现页「动态」无法加载**：页面初始化早于登录状态探测完成，已登录用户被误判为未登录而显示空列表；现在等待状态就绪后再按登录态加载。
- **界面字体错乱**：外观字体此前会影响按钮、分段控件、列表标题等全部界面控件（截图中等宽字体污染），现在仅作用于正文阅读文本，按钮与控件保持系统字体，符合平台规范。
- **分段控件样式**：过高的胶囊外形统一收敛（紧凑密度、小圆角、细描边），与周边元素对齐。
- **首页「加载更多」按钮**：改为滚动到底部自动加载，列表尾部显示加载指示。
- **搜索入口精简**：移除首页重复的搜索框样式按钮，只保留标题栏搜索图标。

## 改进

- 主题层字体逻辑收敛：九处组件级字体覆写移除，统一由正文三档样式承载；等宽字体仅用于代码编辑器、日志与代码片段。
