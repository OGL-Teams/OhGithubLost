# v13.2.0（beta 预发布）

本版按品牌与文案规范重写了项目自述文档，并改进了授权登录方式。这是 v14 正式版前的第二个 beta 预发布版本。
This release rewrites the project README according to brand and copywriting standards and improves the authorization sign-in flow. It is the second beta before the v14 stable release.

## 登录 / Sign-in

- 授权登录改用**浏览器授权**：点击「授权登录」后自动打开浏览器，登录 GitHub 并点一次 Continue 即完成，无需抄写设备码、无需等待轮询。
  Authorization sign-in now uses browser-based authorization: after tapping Sign in, the browser opens, you sign in to GitHub and press Continue once — no device code to copy and no polling to wait for.
- 授权基于 OAuth App 网页流程与本地回环回调：令牌仍只保存在本机保险库，客户端不接触任何密钥。
  The flow uses the OAuth App web authorization with a local loopback callback; tokens remain in the on-device vault and the client never touches secrets.
- 若浏览器授权不可用（如网页版环境），自动回落到原有的设备码方式；经典令牌登录不受影响。
  If browser authorization is unavailable (for example on the web build), the app falls back to the original device-code flow; classic token sign-in is unchanged.
- 此前部分用户反馈授权登录隔日失效：经排查，令牌本身没有有效期，失效源于设备码轮询链路不稳；新的网页授权一次跳转完成，不再经过该链路。
  Some users reported next-day sign-out with the previous flow: the token itself has no expiry — the instability came from the device-code polling path, which the new browser flow bypasses entirely.

## 自述文档 / README

- 中文与英文自述文档按品牌文案规范重写：首屏三行内说清项目定位、适用人群与核心取舍；贡献、致谢、平台矩阵、下载入口等事实内容逐项保全。
  Both READMEs are rewritten to the brand voice: the first screen states what the project is, who it serves and its core trade-offs within three lines; factual content — contribution terms, acknowledgements, platform matrix and download links — is preserved item by item.
- 中英两版章节一一对应，链接集合完全一致。
  The two versions keep one-to-one section alignment and identical link sets.
