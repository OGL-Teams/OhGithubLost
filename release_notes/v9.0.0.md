## 修复 · Fixed（修复前 → 修复后）

### AI 配置 HTTP 端点崩溃
- **修复前**：填 `http://` 端点直接崩，用户不知错在哪。
- **修复后**：http/https 均可用，输入框即时校验收据，明文给出知情提示。

### AI 底层错误未捕获
- **修复前**：TLS 握手、密钥存储异常静默穿透，点保存毫无反应。
- **修复后**：`IOException` 兜底 + 设置页宽泛 catch，任何失败可见。

### 下载「完成却卡在下载中」
- **修复前**：完整性校验抛错导致状态永停。
- **修复后**：收尾加顶层兜底，异常如实标记失败并留日志。

### Web 版长期无法构建
- **修复前**：自 v7.x 起持续失败（http 依赖缺失 / isolate_manager 拖 dart:html /
  window_manager 拖 dart:io）。
- **修复后**：补依赖 + 依赖覆盖 + 平台隔离壳，Web（wasm + js）双构建稳定通过。

### 用户故障无日志可查
- **修复前**：debugPrint 吞错，release 下剥离，无痕迹。
- **修复后**：surface 层统一接入日志系统，可追溯。

### 剪贴板静默失效
- **修复前**：外链/路径复制在 Web 端无声失败。
- **修复后**：统一封装 `ogLCopyText`，失败可见。
