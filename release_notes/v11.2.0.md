# v11.2.0

## 新增

- **发现页重做**：微博式上下滑动信息流。三个左右滑动子标签——
  - **动态**：star 仓库的 Release / Tag 发布卡片流（无 Release 时回退最新 tag）；
  - **推荐**：高星热门仓库纵向列表（匿名可用）；
  - **Issues**：聚合「我提出的」与「star 仓库新提出的」open issue，新的在上，支持 全部 / 我的 / Star 三档筛选。
- **仓库页右上角搜索**：一键进入代码搜索结果页，自动预填 `repo:<当前仓库> ` 限定词。
- **AppBar 滚动渐变融合**：随滚动从页面背景色（surface）连续插值到浮起色（surfaceContainer），取消阶跃色块与硬边；主题层把 appBarTheme 统一为融合基线，覆盖全部页面。

## 修复

- **文件提交不可用（P0）**：`RepositoryCache` D1 原先对「远端不存在 + 无基线」一律拦成 `requiresRead`，空串基线又触发 D2 恒真 staleSha——新建文件与草稿保存 100% 失败。现修正为：远端已存在且无基线才拒绝；远端不存在且无基线为合法新建（GitHub 以「无 sha 即拒绝覆盖」兜底），且空串基线不再发 `sha: ''`。
- **下载**：`resolveDownloadUrl` 预签名失败不再静默回退，写带原因的可见日志；全链路审计确认门禁白名单、签名地址与令牌出口逻辑无代码缺陷。
- 版本常量与 `pubspec.yaml` 同步，关于页显示正确版本。

## 改进

- 设置页文案精简；法律文本权威化（唯一生效的是 LICENSE 全文，译本以英文原文为准）；首次引导亲人版压到三句以内。
- 加速管理细化：9 类独立区域开关（新增 5 类默认关）+ API 兼容性与易泄露警示卡。
- 仓库 code 页空白修复：404 仅在「仓库确实为空」时算空、目录响应严格数组校验、空结果不写入快照、排序缓存改用内容指纹。
- 六语言（简中/繁中/英/德/法/俄）同步全部新增文案。

## 已知限制

- Actions 日志 / 头像加速开关为预留项，本版未接入取数链路。
- 未登录时「我 star 的仓库」如实展示为空/错误态。
