# v7.4.3 · Web 冷启动治本（CanvasKit 同源 + dart2wasm 打通 + 部署链路修复）

## 一、本版解决的三个真问题

### 1. 国内冷启动慢：CanvasKit 走 Google CDN（**主因**）
Flutter 默认让 `flutter_bootstrap.js` 从
`https://www.gstatic.com/flutter-canvaskit/<hash>/` 拉 CanvasKit
（`canvaskit.js` + `~1.5MB` `canvaskit.wasm`）。**该域名在国内基本不可达**，
首屏卡在等待超时——与主包大小无关，与 wasm 也无关。

**修法**：构建加 `--no-web-resources-cdn`
→ CanvasKit 打进产物 `canvaskit/`，bootstrap 改写为同源相对路径。
构建配置里可见 `"useLocalCanvasKit":true`（已核验）。

### 2. dart2wasm 编译被 transitive dep 卡死
```
re_editor → isolate_manager ^4.1.5+1 → isolate_contactor ^4.0.0
                                      → dart:html   ❌ dart2wasm 不支持
```
`isolate_contactor 4.2.0` 虽已迁到 `package:web`，但约束 `web: ^0.5.1`
（0.x 的 caret 锁死 minor → `<0.6.0`），与 `http 1.x` 需要的 `web: ^1.0.0`
**冲突** → pub 只能退回 4.1.0。

**修法**：`dependency_overrides: isolate_manager: ^6.3.2`
- 6.x **彻底删除** `isolate_contactor`，自身直接用 `package:web`（`web: ^1.0.0`）
- API 与 re_editor 用法一致：`IsolateManager.create(fn, concurrent: n)` /
  `.compute(p, callback:)` / `.stop()`
- lib/ 内零 `dart:html`
- 只改版本求解，不动第三方源码

### 3. 部署链路：`[skip ci]` 把 Netlify 也跳过了（**产物从没上线**）
CI 提交 `app/` 用 `[skip ci]` 防自触发——但 **Netlify 对含 `[skip ci]`
的提交同样跳过构建**。结果是 app/ 产物只进了仓库、从没部署到站点
（站点长期停在 v7.4.1）。

**修法**：
- 提交信息去掉 `[skip ci]`
- 防自触发改用 workflow 的 `paths-ignore: ['app/**']`
  （GITHUB_TOKEN 推送本身也不会触发新 Actions 运行）

### 4. Netlify 缓存策略没生效（`_headers` 放错位置）
`_headers` 原先生成在**版本桶**里（`app/js/<v>/_headers`），但 Netlify
只读取**发布根**（`app/`）下的 `_headers` → 线上所有资源都是
`max-age=0, must-revalidate`，每次访问都要回源校验。

**修法**：`tool/web_publish.py` 在发布根写 `app/_headers`：
- `/`、`/index.html`、`/versions.json` → 始终校验（新版本立刻可见）
- `/wasm/*`、`/js/*`、`/7*`、`/v7*` → 一年 `immutable`（目录名含版本号）

## 二、产物结构

```
app/
├── index.html          ← 入口：双层 wasm 嗅探 → iframe 分流
├── versions.json       ← [{version, dir, variant:'wasm'|'js'}]
├── wasm/743/           ← dart2wasm 主载 + canvaskit/（同源）
├── js/743/             ← dart2js 兜底 + canvaskit/（同源）
└── 741/ 740/ …         ← 历史版本保留
```

## 三、入口页分流

顶部**同步**嗅探（iframe 取 src 前必执行完）：
1. 基础 `WebAssembly.validate(...)`
2. **Wasm GC struct/array ref** 字节序列（dart2wasm 必需）

→ `window.__OGL_VARIANT__ = 'wasm' | 'js'` → iframe 指向
`./wasm/<版本数字>/` 或 `./js/<版本数字>/`。

## 四、浏览器兼容

| 浏览器 | 最低版本 | 走哪条 |
|---|---|---|
| Chrome / Edge / Opera / Brave / Arc | 89+ | wasm |
| Firefox / LibreWolf | 89+ | wasm |
| Safari / iOS Safari | 16.4+ | wasm |
| 更老 | — | js 兜底 |

## 五、其他
- `tool/web_publish.py`：`--subdir wasm|js`；`versions.json` 带 `variant`
  并按 `(dir, variant)` 去重；旧 manifest 向后兼容
- `web/_headers`：Netlify CDN 一年 `immutable` 缓存
- `assets/i18n/index.json`：i18n 清单
- CI 校验加 `canvaskit/` 存在性断言（防 `--no-web-resources-cdn` 被摘掉）
