## 修复 · Fixed（修复前 → 修复后）

### 用户故障无日志可查
- **修复前**：surface 层多处 `catch` 块里的错误只走 `debugPrint`，release 下被剥离、
  不落盘、也不进通知中心——用户点「保存/复制/打开设置」失败时，既看不到提示，
  排查也没有任何痕迹。
- **修复后**：7 处接入 `OgLAppLog`（统一日志系统），失败以 warning 级落盘、
  可追溯；base/platform 层 7 处保留 `debugPrint` 但补注释说明原因（无注入点、
  平台层禁全局单例）。

### 测试偶发不稳定（flaky）
- **修复前**：网络重连测试用 20/30ms 硬编码时序，慢 CI 上偶发失败；
  日志文件测试跨午夜墙钟不一致会挂；截屏矩阵测试改了视口尺寸不还原。
- **修复后**：加大时序容差 + 显式 timeout；日志测试改用后端实际文件名而非墙钟；
  截屏测试补 `addTearDown` 还原视口。

### Web 版构建稳定性（平台差异文件防串线）
- **修复前**：main ↔ web 分支同步时，`pubspec.yaml` / `desktop_window.dart` /
  `surface_bridge.dart` 等平台差异文件被误覆盖，导致 Web 构建反复失败
  （`dart:html` / `dart:io` / `webStartup` 缺失三类错误交替出现）。
- **修复后**：明确 web 树 4 个「平台差异文件」清单，恢复正确版本，
  Web 构建稳定通过。
