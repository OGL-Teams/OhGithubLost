# v10.4.0

## 修复

- **仓库 code 页空白返回**：Contents API 的响应曾因三处非法折叠变成空列表——
  - 任意 404 被当作空目录；现仅 `Git Repository is empty` / `This repository is empty` 算合法空，其余（分支失效、无权限、路径不存在）如实显示错误面板。
  - `jsonAsList` 解析失败静默返回空；现目录响应严格校验为数组并逐条映射，失败抛错可见。
  - 空结果写入 6 秒分页快照 / 排序缓存用 List 身份判断（永不失效）；现空结果不进快照，排序改用长度+首尾指纹，切目录不再显示旧数据。

## 新增

- **发现 tab**：原「搜索」改为「发现」。搜索框下方是「我 star 的仓库」与「热门推荐」（高星仓库，匿名可用）；提交搜索进入独立 `SearchResultsPage`，仓库 / 代码两模式结果不挤占首页。
- **加速区域细化**：`OgLAccelScope` 从 4 类扩到 9 类，新增 Gist 文件、仓库归档 ZIP、README 外链图片、Actions 日志、头像；新增 5 类**默认关**，既有 4 类行为不变。已接入 Gist 文件下载、code 页「下载 ZIP」、README 第三方图床图片；Actions 日志与头像保留开关但本版不接入（注释说明原因）。
- **风险警示**：设置页加速分节顶部新增暗红警示卡，明确说明第三方通道可能丢请求头 / 不支持 Range / 改写响应（**API 兼容性与空返回风险**），以及请求经由应用外服务器、令牌与签名 URL 的**泄露面**。

## 改进

- 设置页删除大量冗长说明与动效档位四行长文，条目更紧凑。
- 法律文本权威化：唯一具法律效力的是仓库根目录 `LICENSE`（Apache License 2.0）全文，本页仅为说明、不增减权利义务；译本以英文原文为准。
- 首次引导「亲人版」压到三句以内，去掉官话。
- 六语言（简中/繁中/英/德/法/俄）同步全部新增文案。

## 已知限制

- Actions 日志 / 头像加速开关本版为预留项，未接入取数链路。
- 未登录时「我 star 的仓库」如实展示为空/错误态。
