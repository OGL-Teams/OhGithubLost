# v12.3.0

## 改进

- **全局气泡宽度统一**：应用内所有短提示（保存结果、错误横幅、下载提示）改为同一规格，左右留隙恒等，不再因页面不同而长短不一。
- **设置页文案重写**：逐条改写为简短直述，去掉背景叙述与第二人称；各项之间的上下间距统一，不再有分组内外两套留白。
- **发现页信息密度提升**：动态与问题改为紧凑行式（状态竖条 + 单行标题 + 次要元信息）；推荐仓库改为宽屏双列网格，说明与版本号等次要信息降级显示；新增相对时间（刚刚 / N 分钟前 / N 天前）。
- **文件编辑器**：顶栏改为可左右滑动的单行工具栏，窄屏不再出现图标挤压重叠；新增底部状态栏（行数、字符数、行列位置、编码、未保存标记）；查找条计数与等宽字体统一。
- **搜索仓库入口**：首页顶部新增搜索框，标题栏右侧新增搜索图标，两处均可直接进入仓库搜索。

## 说明

- 网页版的重构范围已定稿：保留完整运行框架、全部仓库功能、网络与加速、缓存体系；仅精简浏览器上不成立的外围功能。将在后续版本提供。
