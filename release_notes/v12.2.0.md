# v12.2.0

## 新增

- **GitHub 账号授权登录**：以组织名下 OAuth App 的设备流登录，登录页显示一次性代码与官方授权页地址；授权页显示应用归属与权限范围，确认后令牌仅存于本机安全存储，退出登录即删除。未配置授权的构建自动隐藏该入口，个人访问令牌登录不受影响。
- 启动时校验账号令牌是否仍在（保险库内容缺失时直接进入登录门，不再以「未登录」身份发起注定失败的请求）。
- 账号元数据损坏时改为隔离并告警，令牌保留可人工排查，不再静默删除。

## 改进

- 界面字体子系统：字体下载后落盘缓存，冷启动不再重复下载；未注册字体的回落会记录日志，便于排查「选了字体却没变化」。
- 界面各处文字样式统一跟随所选界面字体。
- 登录状态机的通知加入同值短路，避免无意义的重复刷新。

## 修复

- **私有仓库图片预览不再经第三方通道**：此前开启加速后，浏览私有仓库时每张图片都会把访问令牌发送给通道服务器，且无任何确认与记录；现已改为直连官方地址。
- **议题锁定功能不可用**：请求方法与服务端不符，现已更正，并新增回归测试锁定各写操作的请求方法。
- 列表类接口收到格式异常的响应时不再静默显示为「暂无数据」，而是如实报错。
- 添加仓库到下载的入口在私有仓库加速时此前会跳过令牌出设备的确认警告，现已与其它下载入口一致。
- 部分情况下启动后界面反复刷新的问题。

## 说明

- 本应用使用 GitHub 设备流授权，全程不需要 Client Secret；应用也绝不收集或请求该凭证。
- 建议为应用配置设置页中的加速通道时知悉：开启私有内容加速意味着相应请求会经过该通道服务器，应用内已有不可关闭的警告与记录。
