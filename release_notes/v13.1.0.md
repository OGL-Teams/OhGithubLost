# v13.1.0（beta 预发布）

本版依据 UX 写作规范重写了界面文案，并按文档架构规范重组了技术文档。这是 v14 正式版前的第一个 beta 预发布版本。
This release rewrites interface copy according to UX-writing standards and reorganizes technical documentation following documentation-architecture guidelines. It is the first beta before the v14 stable release.

## 文案 / Copy

- 修正 22 个界面文案键：错误消息写明具体后果与可逆性边界，空态给出下一步操作，按钮标签统一为动词式表述。
  22 interface strings corrected: error messages state concrete consequences and reversibility, empty states suggest the next action, button labels use verb-first phrasing.
- 简体中文与英文同步修订；其余语言将在后续增量翻译管线中跟进。
  Simplified Chinese and English are updated in sync; other languages follow via the incremental translation pipeline.
- 审计记录见 `docs/UX_WRITING_AUDIT.md`。
  The audit record is kept in `docs/UX_WRITING_AUDIT.md`.

## 文档 / Documentation

- 文档索引按 Diátaxis 四型（教程 / 操作指南 / 参考 / 解释）重组，补齐漏登记文档并逐篇标注类型与状态。
  The documentation index is reorganized by Diátaxis types (tutorial / how-to / reference / explanation), with missing entries registered and each document typed and status-marked.
- AGENTS.md 按当前代码与脚本逐条核实，更新四处过时项（分层白名单归零、CI 门禁清单补全、语言目录口径、文档索引入口）。
  AGENTS.md is verified item by item against code and scripts; four outdated entries are corrected.
- 架构文档的历史待收敛项改写为「已全部收敛」并补充收敛细节。
  Historical convergence items in the architecture document are rewritten as resolved, with details.

## 检查 / Verification

- 十一支门禁与元验证通过；键集合、键顺序与占位符零差异；dart format 与 CI formatter 对齐。
  Eleven gates and meta-verification pass; key sets, order and placeholders unchanged; formatting matches the CI formatter.
- 类型检查与单元测试由持续集成裁决通过。
  Type analysis and unit tests pass in continuous integration.

## 预发布说明 / Pre-release Note

- 本版本为 beta 预发布（prerelease），供提前验证文案与文档变更；正式功能发布将随 v14 稳定版到来。
  This is a beta pre-release for early validation of copy and documentation changes; the stable feature release ships as v14.
