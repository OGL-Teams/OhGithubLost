# v11.5.0

## 新增

- **外观字体管理**：界面字体可选系统默认、内置等宽字体 Ubuntu Mono、思源宋体（首次选择时下载），并支持添加私有字体（本地文件或链接，.ttf/.otf）；私有字体可随时删除，删除当前使用中的字体会自动回落系统默认。
- **Android 5.1（API 22）起全版本支持**：安装包最低系统要求显式固定；存储权限在各系统版本间自动回退（请求失败自动降级，最终以真实写入确认）。
- **自包含等宽字体**：应用内置 Ubuntu Mono，代码、日志与文件名在 Windows / Linux / Android 上观感一致，不再依赖系统是否安装等宽字体。

## 改进

- 设置页「界面」分组新增字体选择与管理入口，子项层级跟随所属功能。
- Windows / Linux 的网络连接说明更明确：证书校验走系统证书栈，不旁路、不静默。

## 修复

- 代码与日志的等宽显示在部分 Linux 发行版下字体缺失或不对齐的问题。
