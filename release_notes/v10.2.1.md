# OhGithubLost 10.2.1

本版本补齐仓库设置、通知、日志、个人资料与搜索处的多项缺失能力，并修复下载与提交结果的通知链路。

## 修复 · Fixed

- 下载完成与失败此前没有任何提示：结果只写进内部记录，离开下载页就再也看不到。现在会进入通知中心并在通知列表与首页角标上呈现。
- 无写权限的仓库（游客浏览、星标仓库、仓库详情暂未取回）不再显示新建、删除、重命名与仓库设置入口，避免点击后才报权限错误。
- 仓库设置页对非管理员只显示说明，不再展示点下去必然失败的改名、Pages 与自定义域名表单。
- 登录时若令牌未能正确保存到本机，不再继续进入主界面，而是提示并保留原账号状态。
- 移除当前账号时若其余账号无法使用，不再留下「显示已登录但无有效令牌」的状态。
- 项目位置与 Actions 运行列表此前只加载第一页（最多 10 条），现在可以继续加载。
- 「文件夹优先」排序开关此前保存后不生效，现已接入目录排序。
- 消息说明与法律提示中的格式符号此前原样显示，现按排版渲染。

## 新增 · Added

- 仓库设置支持切换默认分支、归档与取消归档（均带二次确认）。
- 草稿箱可直接在编辑器中打开草稿，并从起草时的版本继续，仍会走冲突检查。
- 通知中心新增「未读」筛选；日志页支持一键复制整份日志。
- 首页星标为空时提供「去搜索仓库」入口；下拉可刷新。
- 搜索改为输入即搜（停顿约 0.3 秒后发起），清空输入即复位，无需再按回车。

## 改进 · Improved

- 个人资料页支持下拉刷新；账号列表整行可点切换，当前账号以勾选标识。
- 首页切换「我的/星标」不再重新请求与清空列表，切回时保留原有内容。
- 关于页的仓库地址与开源许可整行可点击打开。
- 通知列表的空状态改为带图标的统一空态。

## 变更 · Changed

- 通知与日志的来源打通：运行中产生的通知会同时出现在通知中心与应用日志中。
