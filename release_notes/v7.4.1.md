# v7.4.1 · Web 兼容性收口（不破坏 main 发布线）

## 一、本次定位

Web（wasm）分支上一轮的接入面补得很激进——下载走浏览器、launched by 浏览器、剪贴板用 `Clipboard.setData` 裸调用……但有几处对 Web 的特殊约束摸得不够深。v7.4.1 在不动架构、不引入依赖的前提下，把**已知会引起"Web 上看起来对、实际错"**的接缝收一遍。**main 分支不受影响**——这批改动只在 web 分支。

## 二、修改总览（11 个文件）

### 1. 剪贴板：13 处裸 `Clipboard.setData` 全替换为 `ogLCopyText`
- 新增 `lib/surface/util/clipboard_x.dart`——单一入口封装，捕获异常 + 失败 toast。
- 替换清单：
  - `download_manager_page.dart` 2 处（Download / SavePath）
  - `settings_page.dart` 1 处（_copyLogs）
  - `repo_page.dart` 3 处（_copyCloneUrl / entry.path / _copyPath）
  - `notifications_page.dart` 1 处（拆出 _copyEntryText，失败不弹 toast）
  - `drafts_page.dart` 1 处（拆出 _copyDraft，**仅复制成功才关闭对话框**）
  - 已有：release_detail 2 处、gist_detail 1 处、about 1 处
- 删掉所有页面的 `import 'package:flutter/services.dart'`（已无 Flutter services 调用）。

### 2. localStorage 错误全路径上报
`lib/base/disk/platform_web_impl.dart` 的 5 处 catch（read / write / remove / has / keys）：
- 已有 `catch (error)` 接异常对象（不再吞）
- 加 `OgLAppLog.instance.add('存储', 'localStorage 操作失败：$error', severity: warning)`——关于页能看见。

### 3. JSON 损坏上报（base 分层对等设施）
`lib/base/disk/disk_draft.dart:88` / `disk_journal.dart:146`：
- 改 `catch (_)` → `catch (error)`，加 **KernelDiagnostics 警告**（base 层不能用 OgLAppLog，分层审计守住）。
- code `OGL-DRAFT-401` / `OGL-JOURNAL-401`，data 携带 error 字符串——通过 base_bootstrap 落盘后可在磁盘日志里 grep。

### 4. navigator.storage.persist 结果记录到内核日志
`lib/base/base_bootstrap.dart`：
- 启动时调 `navigator.storage.persist()`（Web 独占），结果写 `OgLLogFile.line('boot.persist', 'persistent=true/false …', level: INFO/WARN)`。
- 关于页直接能看到 `persistent=…` 行——判断浏览器是否会主动清本地存储。

### 5. 浏览器通知：区分"被拒绝"与"不支持"
- `lib/surface/app/browser_notify_web.dart`：新增 `ogLBrowserNotifyPermissionAsync()`，用 `navigator.permissions.query({name:'notifications'})` + 动态 `state` 字段读取，失败回退 `Notification.permission`。
- `system_notifier.dart` Web 初始化改用 async 版本，能区分 `denied`（"浏览器通知已被用户拒绝"）和 `unsupported`（"浏览器不提供 Notification API"）——之前两路都报"不支持"。
- 实现了 `dart:js_interop_unsafe` 的最小使用——只用在读动态字段 `state` 上，不滥用到静态声明。

### 6. 打开本地按钮在 Web 上隐藏
`lib/surface/pages/download_manager_page.dart`：
- `if (!kIsWeb)` 包住 IconButton——Web 用户根本看不到"打开"按钮（点了也是空）。
- `_openLocal` 内部按 `kIsWeb` 分流：Web 走 `Uri.tryParse(savePath) ?? Uri.parse(task.url)`，原生走 `Uri.file`。
- 失败兜底从静态"拷贝已复制"切到带 `{reason}` 的 `downloadOpenFailed`。

### 7. `pathFor` 接口改为可空 `Uri?`
`lib/domain/ix/ix_download.dart`：
- 抽象方法 `Future<String> pathFor` → `Future<Uri?> localUri`。
- web 实现：返回 `null`（Web 没有真实本地路径）。
- io 实现：返回 `Uri.file(spec.savePath)`（保留原行为，但走统一接口）。
- 调用点（ix_download.dart）用 `localUri?.toFilePath() ?? ''` 兼容新旧。

### 8. 4 处 dispose 守卫
- `lib/domain/ix/ix_download.dart:_finishTask` / `_fillCompletedSize` 入口守卫：分片任务在后台完成回填时若管理器已 dispose / 任务已移除，直接返回，不再 `_snapshots[id] =` 把条目"复活"。
- `lib/surface/pages/code_editor_page.dart:_onEdit` 守卫：dispose 后不再 schedule 落盘 / setState。
- `lib/surface/pages/dashboard_page.dart:_RepoPaged.refresh` 守卫：避免"幽灵请求"。

### 9. `IxDownloadFailureReason` 枚举补 `notSupported`
- Web 后端 `_rejectUnsupported` 走诊断通道（`OGL-DL-501`），不返回失败原因；保留枚举以便未来接入 UI 而不破坏 `.name` 拼写。
- 新增 i18n 键 `downloadFailed.notSupported`（6 语言同步）。
