# v12.5.0

## 修复

- **下载可用性**：后端入队失败（下载库未初始化、存储或磁盘异常）时，任务不再永远停留在「排队中」——改为可见的失败状态，附错误说明与诊断留痕，页面可重试或排查。
- **加速候选**：候选地址为空时不再抛异常导致整条仓库文件下载链路中断，如实回退到直连。
- 编辑器「跳转到行」编译问题修复，状态栏行：列可点击直达定位。

## 改进

- 文件编辑器顶栏可横向滑动、底部状态栏、查找与替换面板，参照 MT 管理器的编辑体验整理。
- 全局气泡宽度统一、设置页文案与间距统一、发现页紧凑信息流与宽屏双列网格。
- Web 版完成外围功能裁剪与首屏加载优化：语言包合并为单一请求，网络与缓存能力保留。

## 说明

- 本版继续按 LTS 纪律维护；Web 精简仅作用于浏览器版本，原生端全部仓库代码功能保持不变。
